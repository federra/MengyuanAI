# 系统设置模块

右上角“设置”直接打开完整配置面板，默认显示模型配置，不再显示中间入口菜单。面板保留模型配置、提示词配置、风格模板三个 Tab；视频输出默认设置保留在左侧系统设置页。音频不单独设 Tab 或模块。

## 模型分类与继承

模型配置左侧按生文、生图、生视频、生音频分类，采用紧凑无边框文字树，不使用矩形卡片。父节点左侧“>”表示收起，展开后显示向下符号；点击父节点切换展开/收起，同时在右侧查看该类别的默认模型。点击缩进子节点查看该环节配置。环节默认勾选“沿用类别默认模型”，显示生效模型和来源；取消勾选才可填写独立配置，重新勾选并保存则移除覆盖。旧版已保存的逐环节配置保留为独立覆盖，不静默改用新默认。

- 生文：故事写作/修改/提炼、剧本改编/修改、分镜生成/修改、两类质检与修复、台词、镜头提示词、风格推荐、模板建立、资产提取/推荐、声音设定建议、字幕。
- 生图：通用参考图、角色、场景、道具、服饰、站位图。
- 生视频：镜头视频生成。生音频：TTS 配音、配乐；供应商任务能力不同可独立配置。

每项模型保存 provider、model、endpoint、能力类型、超时、credentialRef；能力由所属类别确定。新任务解析“项目明确选定的视频模型 > 环节独立配置 > 类别默认模型”；无配置显示未配置，真实任务提交时要求补齐可用路由。项目视频输出设置中的演示占位名不覆盖类别默认。原型只模拟任务，不发真实请求；地址格式通过不代表服务连接或 TTS/配乐能力通过。生产凭据保存在服务端。

初次打开时展开生文，其余类别收起；从环节配置入口打开时展开对应类别。各类别可分别展开，折叠不删除配置或草稿。父节点字号14px、子节点13px，行高约30px；选中项用强调色与字重标识，配置来源显示在右侧，不在左侧逐行增加状态副标题。提示词配置和风格模板保持现有导航，不能把模型文字树样式全局应用到其他 Tab。

保存后生效并形成版本；修改类别默认不影响独立覆盖或历史任务。模型页切换类别/环节保留面板草稿；退出未保存内容不写入有效配置。恢复继承不会伪造连接成功。

## 提示词场景与模板

提示词配置沿用同一面板布局：左侧选择场景，右侧选择该场景的具名模板、编辑内容、预览变量，点击“保存并用于此场景”建立绑定。支持新增模板；提示词库和配置中心共用资源及版本。系统场景默认与当前项目覆盖分开保存；优先使用项目场景绑定/内容覆盖，否则继承系统场景模板。恢复项目继承删除该场景的项目绑定与内容覆盖。

工作台已经明确选择的 Skill 或具名方法仍保留，其有效正文单独冻结到任务的 method；场景模板作为调用包装指令，不能静默替换用户选定的方法。必需变量缺失阻止保存，预览显示展开内容；未保存的模板修改在切换场景前应先保存。历史任务保留模板 ID、资源版本、覆盖版本及实际内容。

风格模板包含名称、画面描述与可复用指令，支持新增和编辑。项目引用模板后生成任务冻结版本；模板更新标记依赖媒体需要检查，不静默覆盖已完成视频。

生音频类别统一配置 TTS 与配乐模型，允许各自覆盖；音色、语言、语速与情绪参数属于台词/声音设定，随任务传入。声音资产不等同于模型配置：前者是可复用音色设定，后者负责服务连接。

首批提示词明细见 R4《AI 交互与提示词定制清单》。其中“待接入”项是目标规格，不代表所有模型任务都已在原型实现。配置变更保存版本，旧任务仍显示旧快照。

## 视频输出与导演提示词

系统设置增加视频输出默认设置，维护比例、分辨率与视频模型，按比例计算尺寸。创建项目时以系统默认值初始化选择器，提交后保存项目规格；已有项目保持自己的规格。进入分镜不自动弹出规格设置。服务地址、供应商与凭据引用继续在模型配置中维护；任务快照必须反映项目实际选择的视频模型。

创意/故事/剧本/分镜导演助手分别使用独立修改指令；TXT选题提炼新增独立模板。完整28项见提示词清单。剧本与分镜质检属于生文类，可沿用默认或单独覆盖。写作方法、剧本方法和分镜生成方法下拉菜单显示具名方法，名称关联一个Skill或提示词模板；查看/配置入口打开对应资源；音频配置覆盖逐台词角色音色、语速和情绪。

## 具名方法与提示词库

每个方法有稳定resourceId、名称、来源类型、适用环节及版本。下拉选具体方法，例如“人物弧光故事法”“悬念反转故事法”“三幕分场剧本法”“忠于原作改编法”“连续动作分镜法”“画面节奏分镜法”，不再仅选Skill/提示词类型。按环节过滤，不将质检、TTS等模板放入故事方法菜单。

提示词库与提示词配置中心共用同一份模板数据，支持选择环节、新增具名模板、编辑、必填变量检查、预览和版本化保存。系统模板编辑同时反映在资产库；项目覆盖单独保存，可恢复继承。名称/适用环节/内容不可为空，已发布资源的类型与适用环节不可直接换绑；同环节同类别名称去重。模板更新用于后续任务，不更改历史输入快照；保留已有项目自定义内容。

Skill在资产库新增/编辑，可录入正文或导入Markdown/TXT；原型上限128KB，仅保存指令文本，不执行文件中的代码。新增后自动出现在适用工作台的菜单中。方法选择与模板内容、资源版本、项目覆盖版本一起冻结；修改来源不能依靠显示名识别。

## 本次交互验收

1. 右上角设置一步打开完整面板，只有模型、提示词、风格三个 Tab；音频在生音频类别中配置。
2. 模型父子节点无矩形边框和大块选中背景；鼠标或键盘 Enter/Space 可展开收起，焦点可见，折叠状态可被辅助技术读取。
3. 父节点切换到类别默认表单，子节点切换到对应环节；展开多个类别后选择子节点，能力类型仍与该子节点所属类别一致。
4. 展开、折叠和切换节点保留模型草稿但不自动保存配置；类别默认、独立覆盖与恢复继承的规则不变。
5. 提示词场景选择、模板编辑及风格模板界面保持原样；浅色、深色、晴空蓝、曜夜鎏金主题均可读。


## 生产页面密钥与连接测试（新增授权）

模型配置提供独立“API密钥”密码输入与保存操作，凭据引用仍用于复用。密钥不进入本地草稿、不自动回填，成功保存后清空输入；状态只显示是否配置。明文只在提交与调用时短暂使用，服务端加密保存，浏览器、配置历史、任务快照和普通数据库/媒体备份不包含明文密钥。重启后API与Worker可继续使用；更换服务地址需重新配置对应凭据，不向新地址自动发送旧密钥。

“测试连接”对当前已保存的生文模型发起一次短文本请求，按钮提示会消耗少量供应商用量。模型草稿未保存或凭据缺失时先提示完成配置；调用中禁用重复操作，显示成功及耗时或可操作的鉴权/限流/超时/返回无效等错误，不展示供应商原始错误或凭据。模型、地址或密钥变化后不能继续显示旧配置测试成功。生图/生视频/生音频的实际生成测试在对应媒体适配接入后验收，不冒用生文测试结果。

验收：页面输入并保存 → 刷新只见配置状态、无明文回显 → 测试当前保存模型 → 从创作提交真实文本任务，Worker无需再次手工注入密钥。并验证凭据写入冲突保留输入、失败不误报成功、错误与浏览器存储无密钥、服务地址变更不误发旧密钥。原型仍不接收真实密钥；本节生产工程事实见工程验收记录。

### M2 方舟素材服务配置增量

使用方舟写实人物参考图的视频模型时，生视频配置区提供折叠的“方舟素材上传与审核配置”，包含TOS桶名、地域、火山资源项目和AK/SK密码输入。AK/SK独立于推理API Key，仅通过页面发往服务端加密保存；配置与密钥一起按版本原子提交，保存失败保留当前输入、成功清空密钥，不写入浏览器草稿。离开页面会清除未保存密钥，须清晰提示。保存状态与真实连接/上传/审核状态分开显示，未验证不能标成可用。此配置入口已工程实现，自动上传与审核链仍待实施与真实验收。


## 2026-09-11 风格与具名图片引用增量

内置现代电影、古风写意、清新动画三份可编辑风格模板；新建时补齐缺失种子，不覆盖用户编辑及项目选择。正文包含材质、光影、色彩与运动约束，作为分镜生成和视频任务的真实输入，冻结资源版本与正文；沿用既有配置变更失效传播。

分镜提示词输入 @ 打开本项目已生成图片选择窗口，显示名称、缩略图、类别与确认/过期状态。选择同时写入提示词和本镜对应类别引用；页面展示 @图片名，持久化保留 @[稳定ID]，重名不能通过字符串猜测关联。改名更新显示，不改变原引用身份。AI按显式目录绑定在人物/实体名后放置具名图片引用，发布时转换为稳定引用；无图保留待制作引用，不伪造已生成图片。删除文字引用不自动删除图片栏素材。

时长及视频按钮本轮仅诊断：时长仍来自每镜分镜数据；保存、版本有效及确认要求不变。超限时长不得静默缩短。此前完整图片预览、四类自动引用与实际图片数量显示继续有效。

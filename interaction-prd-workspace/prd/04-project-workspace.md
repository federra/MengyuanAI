# 项目模块

项目页展示项目总数、创作中、已完成、失败任务数；统计取自当前项目和任务记录，不展示无来源增长率。主导航与流程文字为16px半粗，正文15px。

布局从上到下为统计、创建项目、项目记录。创建表单占据上方整行，字段按网格紧凑排布；项目记录在 PC 页面每行三个项目卡，排序与筛选仍在记录标题右侧。窄屏不足以容纳三列时降为单列，避免内容挤压。

创建字段：名称（必填，最多50字符）、类型（营销短视频/通用短视频/剧情短片，可新增并去重）、市场（中文/英文）、风格模板。创建项目选择画幅比例（9:16/16:9/1:1）和分辨率（720P/1080P/4K），初始选项读取系统默认值；不设固定时长。选择结果写入项目生成规格并带入视频与导出；生成设置可统一调整规格与视频模型。风格支持系统设置集中维护。

项目记录卡展示该短片封面、项目名称、类型、市场、当前阶段、状态及更新时间。状态只有“创作中”和“已完成”；完成必须有真实成功导出结果，演示任务不伪装完成。时间格式为“更新于2026-09-08 09:15”。封面优先使用用户选定的短片画面，其次使用该项目视频帧；没有画面时显示空封面。原型中的示例尾帧明确标示，不能用无关装饰图冒充短片封面。

默认按最近编辑倒序；排序支持最近编辑、最早编辑、项目名称。状态筛选支持全部项目、只看未完成、只看已完成；筛选与排序组合生效，无结果给出空状态。继续创作激活对应projectId，各项目的故事、剧本、分镜、导演对话和素材分别保存。编辑与保存更新最近时间，筛选和排序不修改项目时间。

验收：创建时选16:9与4K，后续视频快照、导出设置与下载清单均保持16:9与4K；切换项目分别继承自身规格；卡片包含状态和完整时间；过滤后所有结果符合状态；切换两个项目不会串内容。封面更换只影响当前项目。名称空白、TXT/图片读取失败或本地存储失败应保留当前输入并提示。

# 视觉与交互强制验收（U01–U08）

2026-09-10起生效，适用于生产前端开发、PRD变更同步和最终产品验收。该文件规定验收条件，不是已通过的验收记录。当前生产整体UI仍未通过用户验收，V12/V13生产增量仍待同步。

## 一、基准与退出规则

验收依据依次为最新用户明确决策、正式PRD、R1视觉规范、R2交互原型。开始开发时记录这些文件的版本/提交或内容哈希、受影响页面ID及变更条目；不得拿旧截图或原型演示行为覆盖当前需求。生产真实凭据、版本控制、任务恢复等必要差异单独列明，不能为像素相似删除真实能力。

- **每次前端交付**必须执行受影响页面的U01–U08适用项，提供结果与证据。新改动引起的布局、交互不符合项须当轮修复，不能以“后面统一美化”收尾。既有非阻断差异可按已确定顺序留到最终UI对齐，但须保留问题编号、所属页面、修复阶段，不能标通过。
- **阶段工程退出**：M0–M3按实际涉及页面验收；遮挡或不可达、草稿/版本丢失、重复提交、错误引用、失败状态误报成功等阻断问题未清零，不得关闭当轮受影响工程阶段。已经通过的历史工程验收不因新增UI标准被倒写为失败，新需求走增量验收。
- **最终产品退出**：在M3真实链与独立试用之后完成一次全范围UI对齐验收，U01–U08全部通过且用户明确接受视觉与操作体验，才可标记本地产品整体通过。M3工程通过、真实MP4通过、用户独立试用通过、视觉交互通过必须分别记录。M4可按用户授权做工程准备，但对外上线同样不得绕过此门槛。
- 未测项记“未验证”，不适用项须说明原因；未经用户明确同意，不得擅自豁免硬性要求。用户接受的例外记录具体页面、差异、理由和适用版本，不能扩大成全局豁免。

## 二、可核对的硬性条件

| 编号 | 通过条件 | 必要证据 |
|---|---|---|
| U01 信息结构与布局 | 五大模块、五阶段、工作台标题与最新版PRD一致。创建项目在记录上方、PC卡片三列；创意无助手、115px初始输入框、方法/数量/生成操作横排；故事起保留助手；分镜六列、逐句TTS、规格标签、导入入口必须齐全。不得以相似功能替代规定位置和流转。 | 同数据的原型/生产页面对照；逐项检查表 |
| U02 字体与四主题 | 全部使用无衬线字体。按R1：标题28、章节18、小节16、菜单/流程16、正文/输入15、分镜正文14、操作14、辅助13px；V13 TTS/规格标签12px、模型树父14/子13px为明确例外。禁止再缩字塞布局。浅色、深色、晴空蓝、曜夜鎏金完整覆盖正文/输入/弹窗/表格/错误态；主题不影响成片风格和媒体原色。 | computed style/实际字体检查；四主题截图和主题切换记录 |
| U03 对齐、可读与滚动 | 按钮和选择框按R1规定横排或纵排；同组应对齐的边缘差≤2 CSS px。主要按钮/选择框44px；模型文字树约30px行高（±2px）。正常正文与背景对比度≥4.5:1，主标题≥3:1；状态同时有文字，不单靠颜色。整页无意外横滚，分镜只在表格容器局部横滚。流程栏到顶栏下方后吸顶且不遮挡内容；关闭/保存/生成按钮始终可达。 | 尺寸/对比度记录、长页滚动及弹窗截图 |
| U04 核心任务与绑定 | 创意1/2/3份按选择生成；方法与模板资源一致；建议采用前正文不变；质检未通过也可保留当前版继续。风格正文、图片版本/引用顺序、lineId及台词进入实际生成请求。单镜参数只覆盖本镜；并行排除尾帧依赖，失败只重试对应项。JSON合法导入整体替换所有行，旧版归档，重载一致；非法/保存失败不改原表。 | 生产浏览器交互回归 + API/任务快照核对；替身与真实调用分别标注 |
| U05 状态与反馈 | 空、加载、提交中、成功、失败、过期、冲突均有明确可读状态及下一步操作。禁止加载中先假显示“零项目”，禁止只返回taskId即显示媒体成功。连点不重复提交；局部失败不锁死无关镜头；顺序链缺前镜时有明确原因。长错误码可复制/展开，不能只显示无法辨识的截断文本。 | 各状态截图/录屏、重复提交与失败恢复记录 |
| U06 草稿与版本安全 | 切主题、收起/弹出助手、开关设置、切配置Tab不丢草稿或选中方法；离开尚未保存内容有保留/恢复路径。刷新恢复正式数据；来源变化拒绝覆盖并保留用户输入；迟到响应不可覆盖新版本；导入/切项目不得串数据。 | 刷新、冲突、切项目、迟到响应的浏览器与数据断言 |
| U07 键盘与适配 | Tab焦点顺序可理解且焦点可见；控件有可访问名称。模态窗口焦点进入并限制在弹窗内，关闭恢复触发器焦点；不支持关闭的提交态须说明原因。200%浏览器缩放仍可完成主操作，允许容器滚动但不能遮挡按钮；减少动态效果开启时无强制动效或滚动锁定。 | 键盘、缩放、减少动态效果的实际操作记录 |
| U08 用户视觉与操作接受 | 工程人员完成证据与问题清单后，用户实际检查代表页面并确认整体简洁、层级清楚、字号适中、交互符合预期。自动截图比较或测试通过不能代替用户意见；未回复不算通过。 | 用户原话/日期/对应版本；仅能填写待验收、通过或未通过 |

## 三、执行覆盖与判定

主验收视口1440×900，浏览器缩放100%；补充1280×800与1920×1080检查适配，1440×900另做200%缩放。固定浏览器版本、系统字体、数据集、页面状态；等待字体/媒体/加载完成，关闭进入动画后取稳定截图。不能用空白页面避开长数据，不能用缩小浏览器画面伪装合适密度。

最终覆盖项目、创意、故事、剧本、分镜、导出、资产、任务记录、系统设置九类页面的四主题主状态；模型/提示词/风格设置、元素管理、单镜规格、JSON导入等弹窗四主题均检查文字与主操作。状态集至少包括：空项目、多项目三列、1/2/3份故事、长故事、11镜及多角色多台词、同类多图、长提示词/错误信息、并行部分失败、尾帧缺失、导入成功/失败、版本冲突、导出待更新。数量是覆盖样本，不是产品限制。

每次增量只重测受影响页面及公共组件的连带范围；修改主题/字体/公共导航时扩展到九页四主题。可用隔离API替身触发难复现状态，但必须另列真实API保存重载/版本/素材绑定的验证结果。不得为UI回归自动新开付费生成；使用已有合规素材或隔离替身，真实调用按既有授权执行。

截图不是逐像素复制要求：同视口下核对结构、列数、对齐与R1尺寸；动态时间、真实内容长度、图片和系统字体抗锯齿可产生合理差异。差异须逐条解释；“数据不同”不能解释错误字号、多余列、错误按钮顺序或缺失交互。不得通过更新基线截图让未批准的设计变化自动通过。

## 2026-09-10 参考图标尺修订（当前规则）
本节取代早前的190px选中元素编辑布局、1040px弹窗上限、2×2图片区与表内TTS操作条。主内容使用剩余视口全部宽度，不设最大宽度；四主题共用比例。分镜列为序号、台词、角色/场景/道具、提示词、视频、操作。窄视口允许表格局部横向滚动，不压扁输入与操作。
台词每段为一个矩形卡片，顶栏为说话人、情绪、麦克风入口及删除图标，字段名仅保留无障碍标签；正文下方不显示音色、配音设置或生成第N段按钮。麦克风打开配置弹窗，保留音色绑定、表现、语速、生成、试听和任务故障恢复；打开本身不提交任务。每镜末尾为窄长条“＋ 添加台词”。
图片区为角色、场景、道具、站位四个固定64px方框，竖直排列。空框只显示＋，有图显示缩略图与数量；点击直接打开该类图片选择窗口，可多选与替换，保留稳定引用ID。站位图生成、确认放入站位框窗口，不在表中展开。
提示词正文不显示画面描述/镜头描述/镜头秒数标签，底部依次为模型、画幅、分辨率、时长四项。规格继承生成设置，显式单镜覆盖继续受版本与失效约束；时长保留实际分镜值，修改会保存新分镜版本。导入分镜JSON右侧增加界面设置，按字段切换显示，刷新保留；隐藏只影响显示，不删除或更改业务数据。
角色、场景、道具管理采用宽表同时展示全部元素，列为序号、名称、描述、音色、参考图、图片、操作；场景与道具音色显示不适用。描述即生图提示词；音色从真实声音资产选择，不提供假音色。参考图可上传/清除；输出图展示已选最新结果，角色默认三视图；操作为生图、删除、添加到资产库。历史/确认/绑定能力保留在图片详情中。整表草稿统一事务保存，失败或冲突保留草稿；已引用元素删除须先解除引用，不物理删除历史。
生成分镜时，使用同一次模型响应解析完整剧本全部角色、场景、道具，包含未出镜实体；输出实体目录及每镜/台词的显式实体键绑定。不得从名字猜绑定，不另发付费解析请求。服务端校验后分镜、目录、引用一起事务提交；失败不出现半张表。旧任务按冻结契约恢复；重新生成保留旧目录、素材和历史，不静默覆写人工编辑。来源过期的结果只归档，不激活项目目录。工程替身验证与真实供应商解析质量验收分开。


## 2026-09-10 项目与分镜交互细化（最新用户决定）

本增量验收：四主题下标题信息不增加页高、长文本可读；表头居中；台词与实体控件实测32px、上传清除对齐；图片槽标签不改变64px方形；删除取消/冲突/重复/恢复/隔离；直接生图重复点击与未知结果恢复。替身测试不代表真实供应商或用户视觉接受。

# 单文件交互原型导出

交付文件为 `exports/AI短片工坊-可交互原型.html`，约4.4MB；包含11个页面、内嵌样式/脚本和四主题。无需启动4173服务，使用浏览器直接打开。顶部页面选择可进入组件/状态页，模块和创作阶段保留原跳转。

这是可操作的原型快照，不包含PRD阅读器、文档编辑器或真实AI服务。生成媒体与导出沿用Demo边界；没有自动付费调用。文件仅打包仓库原型源代码，不包含生产项目、浏览器现有数据或凭据。

新演示数据保存在接收者当前浏览器独立存储中；转发HTML不携带编辑结果。浏览器禁止文件持久存储时降级为当前打开期间内存保存并显示提示。清除浏览器存储、换设备或改变文件位置可能导致无法读取原记录。

## 重新生成与验证

从项目根目录运行 `node interaction-prd-workspace/reference/tools/export-standalone.mjs`。打包器使用现有 `apps/web/node_modules/esbuild`，无需修改阅读器或原型源文件；页面清单和所有脚本/样式取自当前原型文件，使用前须已安装工程前端依赖。

`reference/tests/standalone-browser.mjs` 在离线隔离Chrome中以file方式打开成品，检查无HTTP请求、页面跳转、故事→剧本→分镜、设置、主题以及刷新保存；按本机环境配置PLAYWRIGHT_MODULE。此次验证通过。验证数据只存在隔离浏览器，未写入交付文件或生产库。

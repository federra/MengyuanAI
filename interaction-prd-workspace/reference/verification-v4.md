# 五模块重构验收记录

日期：2026-09-07。检查基准：1440×900 的 PRD 原型画布，浅色和深色。未修改 runtime。

## 已验证

- 项目：创建新项目进入创意；两个新测试项目与原项目隔离；切回项目保留6份故事、每页3份。原单项目存储保留，迁移历史候选时按ID去重。
- 故事：生成3份、再生成3份、上/下翻页、修改正文、对话修改、选定并生成剧本。粘贴4段故事直接生成，第四段仍保留。
- 质检：剧本问题报告在右栏；修复产出新版并自动复检；通过后确认分镜。分镜报告建议可应用、复检、人工确认。
- 媒体：四类参考图生成/确认、12个稳定图片引用、独立TTS；按顺序生成三个镜头。演示失败停止后镜，失败任务可筛选并读取配置与错误快照。
- 资产：新增服饰描述、类别筛选、加入项目；分镜角色图存入资产库，再引用回分镜。替换参考图后，三个依赖视频均标记待更新；重新生成恢复。
- 配置：系统设置四入口；故事对话修改模板可预览和保存；保存的风格模板出现在资产库。
- 导出：素材检查通过、模拟导出返回明确“无MP4”结果；点击制作清单下载。JSON包含实际累计镜头时长和导出参数。
- PRD：22模块、11页面、68导航关系通过 npm run validate；21个有效标注均逐项点击验证选中气泡；坐标来自DOM实测。全局画布通过UI自动排列并截图检查，无页面重叠。
- 视觉：项目、故事、剧本、导出、资产、组件与状态页检查；被测页面无整页横向溢出，分镜表允许自身横滚。修复预览文字在浅色主题下对比不足的问题。

## 逻辑检查

Node断言通过：异步写回原项目不改变当前项目；市场进入任务快照；四段故事完整保留；过期质检拒绝；建议应用后复检；前镜无尾帧拒绝后镜；任务结果深拷贝、旧配置快照不受后续修改影响。

未调用真实模型、图像/TTS/视频服务或编码器。TXT文件导入、图片/声音上传具有本地处理路径，本轮浏览器验收重点验证粘贴输入和生成图复用，未逐一测试所有媒体格式。英文市场元数据已校验，示例内容主要为中文，真实跨语言生成以R4用例验收。完整专业多轨编辑与剪映兼容仍为后续项。

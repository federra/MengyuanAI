# V12 项目与创意工作台调整

2026-09-10。本轮仅更新交互PRD与Demo；生产代码、数据库及真实模型未改动。

## 一、当前规则

1. 项目页按统计 → 创建项目 → 项目记录排列。创建表单整行展示，PC记录每行三张卡；原状态、封面、更新时间与排序筛选保留，创建规格继续继承至视频和导出。
2. 创作五阶段导航滚动至顶栏下方后吸顶，四主题共用。创意输入默认115px，标题旁提示“可输入对故事篇幅字数的要求”；创意页无导演助手，故事及后续助手保留。
3. 创意底部方法在左、数量与“AI生成故事方案”在右，选择框与按钮对齐。storyCount为1～3整数、默认3，按项目保存；一批候选共享batchId，任务冻结数量及完整创意。更多沿用数量，每页最多三张；TXT仍仅一张卡且保留原文。
4. 模板新增storyCount变量；旧模板、Skill和历史结果保留，任务另附数量约束。真实工程须验证模型返回数量匹配，篇幅要求进入最终请求，参见R4与R5的V12增量。

# 视觉设计规范 · v11

以用户七张截图的五模块和五阶段结构为准。工作台采用固定188px侧栏、66px顶栏、五等分流程条；内容留白22–30px，正文15px，辅助13px；主菜单和流程文字16px半粗，标题24–30px。分镜大表局部横滚，禁止通过过小字体塞入所有列。

浅色：灰白底、白面板、深蓝灰文字；深色：深海军蓝底、较浅面板、浅色文字。主操作实色高对比，危险操作保留语义颜色。风格强调克制与内容可读性，避免会员卡、机器人和无来源统计。

项目统计4列等宽，项目卡3列，故事三栏为200px候选/弹性正文/290px导演助手；小屏降为两栏。资产3列密集排列，系统设置四项入口（模型、提示词、风格模板、视频输出默认设置），音频归入模型配置。标题全宽、不超过2行。

所有主题共用无衬线字体栈：Satoshi（如本机已安装）→ 系统无衬线字体 → PingFang SC / Microsoft YaHei → Arial / sans-serif。不依赖远程字体；未捆绑 Satoshi 文件，本机实测中文使用苹方、拉丁使用 SF。字体不随主题改变。GSAP使用本地文件，实现内容进入、卡片/图形缩放及标题描述轻微位移；尊重减少动态效果设置，不锁定编辑滚动。

交互优先于装饰：每页一个主任务入口，其余按详情或更多菜单渐进展开。清楚区分真实上传素材和几何示意图，示意图不冒充AI成片。

本轮统一工作台标题28px，章节18px，操作14px。故事、剧本、分镜的导演助手默认右侧，收起至42px边栏，主体自动补位；悬浮模式不预留空白列。创意的方法与数量/生成操作横向并排、底边对齐；其余工作台主要按钮与具名方法按同宽纵列排列，不压缩文字。元素管理以宽弹窗列表与选中编辑区集中管理，角色音色与三视图放在描述下方。用户本轮三张参考图仅借鉴表格结构，不照搬高密度深色样式；原浅色和深色方案保留。

## UI主题与品牌

品牌统一为“AI短片工坊”，左上角采用简洁播放符号。右上角“UI主题”选择器提供浅色、深色、晴空蓝、曜夜鎏金；保留已有偏好。切换只更新主题，不重绘编辑器，不改变视频风格或媒体原色。浏览器保存选择，刷新、页面切换与同源标签同步；存储不可用时仍可在当前页切换。

晴空蓝依据用户提供的导出工作区截图：冰蓝背景#f1f7ff、白面板、主蓝#2463eb、深蓝正文#172b50、轻边框#c5d5ed。主菜单与流程16px，正文15px，分镜正文14px。卡片、表格、导演助手、管理弹窗和导出工作台统一覆盖；媒体内容不做主题滤镜。

应用gpt-taste的字体、层次及轻量进入/滚动动效。本次仅改变工作台主题，沿用现有业务布局，不添加营销模块或滚动锁定。使用已有本地GSAP和ScrollTrigger，尊重减少动态效果偏好。

故事、剧本、分镜沿用V9纵向对齐（创意按V12横排）：方法选择器、查看/配置、生成主按钮同宽同左边缘排列。主工作台操作区最大340px，助手内充满可用宽度；按钮与选择器高度44px。质检区同时提供次要“按建议修改”和主要“保留当前版本并继续”，不用警告弹窗强迫确认。分镜四类参考窗口按2×2紧凑排列，同类图片堆叠；视频角落显示尾帧缩略图，禁用按钮仍保留可读标签。

方法名称是主信息，来源类型（Skill/提示词模板）显示在查看入口，不以类型代替方法名称。资产页增加两类文本资源，正文显示三行摘要。右上角统一“设置”，不新增重复顶栏按钮。

## 设置面板与模型文字树

设置面板沿用四种 UI 主题：右上角直接打开，固定三 Tab。左侧为分类/场景导航，右侧为配置表单，底部固定保存按钮；继承态只读显示有效模型，独立态开放编辑。默认类别与环节覆盖的来源说明放在右侧表单，不在模型左侧逐行增加状态副标题。

模型配置导航改为无边框文字树：父节点 14px、子节点 13px，行高约 30px；父节点使用 > / 向下符号表示折叠状态，子节点缩进；选中项仅强调文字颜色和字重，不使用大面积实色矩形。仅模型 Tab 使用此样式，不改变提示词和风格模板。


## 四主题共用排版与曜夜鎏金

共享样式入口 `prototypes/shared/typography.css` 最后加载，覆盖早期重复字号声明。正文/输入15px、菜单/流程16px、操作14px、辅助13px、标题28px、章节18px、小节16px；长文行高1.8，标题不使用中文负字距。分镜正文14px，模型文字树仍为父14px/子13px/约30px行高。展示页移除无业务意义的编号前缀；保留真实镜头和流程编号。

深色主题将链接与实色按钮分开取色：链接浅蓝#96bdff、按钮#2f6ad9配白字，避免同一个蓝色兼顾文字与底色造成低对比。浅色与晴空蓝保持各自风格，统一字号和字重，媒体原色不变。

第四主题曜夜鎏金（noir）：墨黑底#0d0d10、暖灰面板#19191e、正文#f4efe5、辅助#aaa396、香槟金#dfc18a；按钮配深色字#22190e，使用轻微金色渐变、细线与柔和高光。保留成功/警告/失败语义色。覆盖五模块、创作五阶段、设置弹窗、表格、导演助手、状态页；不改模型文字树的无边框结构。

主题只改变视觉，切换不重绘编辑器，不更改业务数据和媒体输出；沿用原主题存储键并保留旧偏好。验证记录见 [V11 字体与四主题验收](/content/reference/verification-v11-typography-themes.md)。

## V12 项目与创意布局

创建表单置于项目记录上方；PC 项目卡每行三张。创意输入框默认115px，标题旁13px字数要求提示；无导演助手列。写作方法在左、数量与生成按钮在右，按钮和数字框高度44px。五阶段栏采用sticky，顶偏移68px，与顶栏衔接、背景不透明、层级低于弹窗；四主题共用。保持现有无衬线字体和字号，不因增加数量框压缩文字。

## V13 分镜表

表格保持六列：序号、台词、四类参考图、提示词、视频、操作。TTS融入每段台词底部固定28px工具行；小入口12px、无需撑开新列。视频下方以12px短标签展示模型、比例/像素、秒数、分辨率；当前待生成参数与旧视频过期状态区分。风格与绑定台词收在提示词下的折叠区。四主题共用结构，表格允许局部横滚；导入入口与管理工具同行，宽度不足时自然换行。

## 强制验收关联

本规范是生产UI验收基准，不是可选美化建议。测量、四主题/状态覆盖、差异说明与用户接受按 [U01–U08强制验收](/content/reference/ui-interaction-acceptance.md)执行；当前原型表现与规范冲突时不得把冲突自动抄入生产或标通过。


## 2026-09-10 紧凑工作区增量

全局主导航展开188px、折叠68px，偏好在页面跳转及重载后保留；折叠按钮支持Tab、Enter/Space，具有aria-expanded/aria-controls及title。项目文件夹、创作锤子、资产宝箱、任务列表、设置齿轮均为22px currentColor描边SVG。折叠后隐藏标签而保留title和无障碍名称。分镜工具按钮44px高、不缩字，窄宽度仅工具栏和表格局部横滚。六列56/240/232/360/220/72px，共1180px；台词正文14px、64px高、卡片内边距6px，提示词120～160px；四类引用2×2格、图片48px高。视频预览限制160px高、保持比例居中，避免竖屏预览撑高整行。四主题共用几何尺寸，不改变字体体系。


## 2026-09-10 参考图标尺修订（当前规则）
本节取代早前的190px选中元素编辑布局、1040px弹窗上限、2×2图片区与表内TTS操作条。主内容使用剩余视口全部宽度，不设最大宽度；四主题共用比例。分镜列为序号、台词、角色/场景/道具、提示词、视频、操作。窄视口允许表格局部横向滚动，不压扁输入与操作。
台词每段为一个矩形卡片，顶栏为说话人、情绪、麦克风入口及删除图标，字段名仅保留无障碍标签；正文下方不显示音色、配音设置或生成第N段按钮。麦克风打开配置弹窗，保留音色绑定、表现、语速、生成、试听和任务故障恢复；打开本身不提交任务。每镜末尾为窄长条“＋ 添加台词”。
图片区为角色、场景、道具、站位四个固定64px方框，竖直排列。空框只显示＋，有图显示缩略图与数量；点击直接打开该类图片选择窗口，可多选与替换，保留稳定引用ID。站位图生成、确认放入站位框窗口，不在表中展开。
提示词正文不显示画面描述/镜头描述/镜头秒数标签，底部依次为模型、画幅、分辨率、时长四项。规格继承生成设置，显式单镜覆盖继续受版本与失效约束；时长保留实际分镜值，修改会保存新分镜版本。导入分镜JSON右侧增加界面设置，按字段切换显示，刷新保留；隐藏只影响显示，不删除或更改业务数据。
角色、场景、道具管理采用宽表同时展示全部元素，列为序号、名称、描述、音色、参考图、图片、操作；场景与道具音色显示不适用。描述即生图提示词；音色从真实声音资产选择，不提供假音色。参考图可上传/清除；输出图展示已选最新结果，角色默认三视图；操作为生图、删除、添加到资产库。历史/确认/绑定能力保留在图片详情中。整表草稿统一事务保存，失败或冲突保留草稿；已引用元素删除须先解除引用，不物理删除历史。
生成分镜时，使用同一次模型响应解析完整剧本全部角色、场景、道具，包含未出镜实体；输出实体目录及每镜/台词的显式实体键绑定。不得从名字猜绑定，不另发付费解析请求。服务端校验后分镜、目录、引用一起事务提交；失败不出现半张表。旧任务按冻结契约恢复；重新生成保留旧目录、素材和历史，不静默覆写人工编辑。来源过期的结果只归档，不激活项目目录。工程替身验证与真实供应商解析质量验收分开。

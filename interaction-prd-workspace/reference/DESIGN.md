# 视觉设计规范 · v11

以用户七张截图的五模块和五阶段结构为准。工作台采用固定188px侧栏、66px顶栏、五等分流程条；内容留白22–30px，正文15px，辅助13px；主菜单和流程文字16px半粗，标题24–30px。分镜大表局部横滚，禁止通过过小字体塞入所有列。

浅色：灰白底、白面板、深蓝灰文字；深色：深海军蓝底、较浅面板、浅色文字。主操作实色高对比，危险操作保留语义颜色。风格强调克制与内容可读性，避免会员卡、机器人和无来源统计。

项目统计4列等宽，项目卡2列，故事三栏为200px候选/弹性正文/290px导演助手；小屏降为两栏。资产3列密集排列，系统设置四项入口（模型、提示词、风格模板、视频输出默认设置），音频归入模型配置。标题全宽、不超过2行。

所有主题共用无衬线字体栈：Satoshi（如本机已安装）→ 系统无衬线字体 → PingFang SC / Microsoft YaHei → Arial / sans-serif。不依赖远程字体；未捆绑 Satoshi 文件，本机实测中文使用苹方、拉丁使用 SF。字体不随主题改变。GSAP使用本地文件，实现内容进入、卡片/图形缩放及标题描述轻微位移；尊重减少动态效果设置，不锁定编辑滚动。

交互优先于装饰：每页一个主任务入口，其余按详情或更多菜单渐进展开。清楚区分真实上传素材和几何示意图，示意图不冒充AI成片。

本轮统一工作台标题28px，章节18px，操作14px。导演助手默认右侧，收起至42px边栏，主体自动补位；悬浮模式不预留空白列。主要按钮与具名方法按同宽纵列排列，不压缩文字。元素管理以宽弹窗表格集中编辑，角色音色与三视图放在描述下方。用户本轮三张参考图仅借鉴表格结构，不照搬高密度深色样式；原浅色和深色方案保留。

## UI主题与品牌

品牌统一为“AI短片工坊”，左上角采用简洁播放符号。右上角“UI主题”选择器提供浅色、深色、晴空蓝、曜夜鎏金；保留已有偏好。切换只更新主题，不重绘编辑器，不改变视频风格或媒体原色。浏览器保存选择，刷新、页面切换与同源标签同步；存储不可用时仍可在当前页切换。

晴空蓝依据用户提供的导出工作区截图：冰蓝背景#f1f7ff、白面板、主蓝#2463eb、深蓝正文#172b50、轻边框#c5d5ed。主菜单与流程16px，正文15px，分镜正文14px。卡片、表格、导演助手、管理弹窗和导出工作台统一覆盖；媒体内容不做主题滤镜。

应用gpt-taste的字体、层次及轻量进入/滚动动效。本次仅改变工作台主题，沿用现有业务布局，不添加营销模块或滚动锁定。使用已有本地GSAP和ScrollTrigger，尊重减少动态效果偏好。

V9采用纵向对齐：方法选择器、查看/配置、生成主按钮同宽同左边缘排列。主工作台操作区最大340px，助手内充满可用宽度；按钮与选择器高度44px。质检区同时提供次要“按建议修改”和主要“保留当前版本并继续”，不用警告弹窗强迫确认。分镜四类参考窗口纵排，同类图片堆叠；视频角落显示尾帧缩略图，禁用按钮仍保留可读标签。

方法名称是主信息，来源类型（Skill/提示词模板）显示在查看入口，不以类型代替方法名称。资产页增加两类文本资源，正文显示三行摘要。右上角统一“设置”，不新增重复顶栏按钮。

## 设置面板与模型文字树

设置面板沿用四种 UI 主题：右上角直接打开，固定三 Tab。左侧为分类/场景导航，右侧为配置表单，底部固定保存按钮；继承态只读显示有效模型，独立态开放编辑。默认类别与环节覆盖的来源说明放在右侧表单，不在模型左侧逐行增加状态副标题。

模型配置导航改为无边框文字树：父节点 14px、子节点 13px，行高约 30px；父节点使用 > / 向下符号表示折叠状态，子节点缩进；选中项仅强调文字颜色和字重，不使用大面积实色矩形。仅模型 Tab 使用此样式，不改变提示词和风格模板。


## 四主题共用排版与曜夜鎏金

共享样式入口 `prototypes/shared/typography.css` 最后加载，覆盖早期重复字号声明。正文/输入15px、菜单/流程16px、操作14px、辅助13px、标题28px、章节18px、小节16px；长文行高1.8，标题不使用中文负字距。分镜正文14px，模型文字树仍为父14px/子13px/约30px行高。展示页移除无业务意义的编号前缀；保留真实镜头和流程编号。

深色主题将链接与实色按钮分开取色：链接浅蓝#96bdff、按钮#2f6ad9配白字，避免同一个蓝色兼顾文字与底色造成低对比。浅色与晴空蓝保持各自风格，统一字号和字重，媒体原色不变。

第四主题曜夜鎏金（noir）：墨黑底#0d0d10、暖灰面板#19191e、正文#f4efe5、辅助#aaa396、香槟金#dfc18a；按钮配深色字#22190e，使用轻微金色渐变、细线与柔和高光。保留成功/警告/失败语义色。覆盖五模块、创作五阶段、设置弹窗、表格、导演助手、状态页；不改模型文字树的无边框结构。

主题只改变视觉，切换不重绘编辑器，不更改业务数据和媒体输出；沿用原主题存储键并保留旧偏好。验证记录见 [V11 字体与四主题验收](/content/reference/verification-v11-typography-themes.md)。

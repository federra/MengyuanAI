# 视觉设计规范 · v6

以用户七张截图的五模块和五阶段结构为准。工作台采用固定188px侧栏、66px顶栏、五等分流程条；内容留白22–30px，正文15px，辅助13px；主菜单和流程文字16px半粗，标题24–30px。分镜大表局部横滚，禁止通过过小字体塞入所有列。

浅色：灰白底、白面板、深蓝灰文字；深色：深海军蓝底、较浅面板、浅色文字。主操作实色高对比，危险操作保留语义颜色。风格强调克制与内容可读性，避免会员卡、机器人和无来源统计。

项目统计4列等宽，项目卡2列，故事三栏为200px候选/弹性正文/290px导演助手；小屏降为两栏。资产3列密集排列，系统设置五类配置卡。标题全宽、不超过2行。

字体优先Geist，中文回退PingFang SC/Microsoft YaHei；当前未捆绑Geist字体文件，实际以设备可用字体为准。GSAP使用本地文件，实现内容进入、卡片/图形缩放及描述透明度随滚动变化；尊重减少动态效果设置，不锁定编辑滚动。

交互优先于装饰：每页一个主任务入口，其余按详情或更多菜单渐进展开。清楚区分真实上传素材和几何示意图，示意图不冒充AI成片。

本轮统一工作台标题28px，章节18px，操作14px。导演助手默认右侧，收起至42px边栏，主体自动补位；悬浮模式不预留空白列。主要按钮与生成方式同一操作行，较窄宽度自然换行，不压缩文字。元素管理以宽弹窗表格集中编辑，角色音色与三视图放在描述下方。用户本轮三张参考图仅借鉴表格结构，不照搬高密度深色样式；原浅色和深色方案保留。

## UI主题与品牌

品牌统一为“AI短片工坊”，左上角采用简洁播放符号。右上角“UI主题”选择器提供浅色、深色、晴空蓝；保留已有偏好。切换只更新主题，不重绘编辑器，不改变视频风格或媒体原色。浏览器保存选择，刷新、页面切换与同源标签同步；存储不可用时仍可在当前页切换。

晴空蓝依据用户提供的导出工作区截图：冰蓝背景#f1f7ff、白面板、主蓝#2463eb、深蓝正文#172b50、轻边框#c5d5ed。主菜单与流程16px，正文15px，分镜正文14px。卡片、表格、导演助手、管理弹窗和导出工作台统一覆盖；媒体内容不做主题滤镜。

应用gpt-taste的字体、层次及轻量进入/滚动动效。本次仅改变工作台主题，沿用现有业务布局，不添加营销模块或滚动锁定。使用已有本地GSAP和ScrollTrigger，尊重减少动态效果偏好。

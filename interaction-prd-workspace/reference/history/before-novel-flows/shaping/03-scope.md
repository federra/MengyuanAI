# MVP 范围

当前有效范围：用户本轮原型修订，仅“一句话 → 短片”。旧双主线版本已归档至 reference/history/before-single-workflow/；本轮明确指令覆盖旧范围，其他已确认要求继续有效。

一句话创意 → AI 输出剧本 → 人与 AI 对话生成多版 → 逐版加入备选 → 选定终版 → 独立分镜表 → 对照剧本质检 → 报告及建议调整版 → 一键采用/复检/人工确认 → 风格与角色/场景/道具参考图 → 镜头视频 → 配音/字幕/配乐与基础剪辑 → 预览导出。

分镜表包含镜头序号、台词、角色/场景/道具、提示词、视频、操作。台词与提示词支持 AI 生成和人工编辑；图片支持生成、描述调整与上传。模型信息按环节配置；提示词中心和环节就地入口共用配置，风格模板可自定义。三类配置入口始终可见。

产品仍是 PC Web，默认 30–90 秒竖屏；保留浅/深主题按钮与清楚字号。目标仍是消除质检时搬运到外部 Web AI 的操作，保留创作者决定内容与素材的控制权。生成成功不等于用户确认；改动上游内容提示下游影响并保留旧版本。

暂缓故事文本输入、原故事对照审核、参考视频再创作、账号/权限、团队协作、发布排期和运营分析。

未决项仅涉及后续真实实现：模型供应商及能力、媒体规格和价格、字幕与音画同步策略、质检严重度策略及真实效率收益。JSON 报告建议加版本匹配、结构校验及服务端原子更新；原型演示不代表真实 AI 或 MP4 合成已接入。详细验收见 PRD 01–03、R2 主线原型与组件状态及 00 计划。

## 用户明确提出的需求

服务短视频平台营销视频和短视频的创作者、发布者、运营者，提升短视频生产效率与质量。

1. 一句话创作：一句话想法 → AI 多轮引导形成剧本 → 分镜脚本 → 对照剧本质检（信息遗漏、情绪错位、动作逻辑）→ 修改调整 → 选择风格并引入分镜 → 参考图 → 视频 → 导出。
2. 故事改编：输入故事文本 → AI 剧本 → 交叉审核与原故事的贴合程度（剧情遗漏、人物差异）→ 分镜脚本 → 共用后续制作链路。
3. 竞品学习：上传竞品爆款视频 → AI 分镜拆解与爆款分析洞察 → 用户补充自己的想法或参考图 → AI 结合竞品脚本生成新的分镜 → 共用后续制作链路。

风格包括古风、现代等，并支持用户自定义风格模板。分镜脚本随时可编辑。参考图包括角色、场景、道具、站位图等。

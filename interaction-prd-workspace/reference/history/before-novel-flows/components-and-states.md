# 一句话主线原型与组件状态

本轮修订 v2.0：按用户逐项要求，MVP 只保留“一句话 → 短片”。主线原型为 **剧本创作与备选 → 独立分镜与质检 → 成片与导出** 三页；公共组件和状态页保留为控件参考，不作为完整产品流程。模型调用、生成结果及合成均为明确标记的演示。

## 一、剧本对话、备选与终版

F01：输入一句话创意后输出一版完整剧本；继续对话保留上下文并生成更多版本，不覆盖之前输出。每版有可编辑内容和“加入备选”按钮。空创意不生成，空剧本不可加入；生成中禁用重复提交。

F02：加入备选保存当时文本的独立副本。对话稿之后的编辑不改变已有备选；同版同内容不能重复加入。备选区可移出未选版本，点击“选定为终版”后仅一版作为下游来源。已选版本不可直接删除。

F03：没有终版时，独立分镜页展示返回剧本入口。更换终版前说明影响，已有分镜、图片和视频保留，但来源标记过期；按新终版重新生成后再质检和确认。对应 N02、N06 / US-09、US-29。

## 二、独立分镜与质检

F04：分镜使用独立页面，剧本仅作为可展开的对照来源。表格沿用用户截图的结构，正文 16px，表头固定，表格局部滚动，不缩字挤压。

| 字段 | 编辑、生成与状态 |
| --- | --- |
| 镜头序号 | 展示当前顺序；后台稳定镜头 ID 不随排序改变 |
| 台词 | 说话角色、情绪和台词可人工修改；AI 生成可编辑示例；提供台词提示词入口 |
| 角色 / 场景 / 道具 | 各自名称、描述与参考图；支持 AI 生成示意、人工修改描述、上传 PNG/JPEG/WebP、确认选用 |
| 提示词 | 可编辑长文、AI 生成辅助；镜头提示词与生成模板分别可调；保留时长字段 |
| 视频 | 生成、上传、播放已上传视频；显示缺失、生成中、成功示例和待更新状态；未确认素材不能提交生成 |
| 操作 | 上移、下移、向下添加与删除；删镜头前确认并归档旧分镜，不复用稳定 ID |

F05：点击“AI 分镜质检”自动带入选定剧本及当前分镜，输出问题、依据、位置、调整前后对照和完整建议版。维度包括信息遗漏、情绪错位、动作逻辑。演示用内置动作缺失样例，不把无问题示例报告当作真实内容质量证明。

F06：“一键采用建议版”先检查 JSON 结构、来源剧本版本、分镜版本及镜头 ID，再一次性更新当前版；旧版归档。仅允许建议修改声明的文本字段，AI 不替换用户上传图片或视频。受影响素材保留并撤销确认、标记视频待更新；无关镜头保留。旧报告随修改失效，复检完成后仍需人工确认。结构错误或过期报告禁止套用，部分解析成功也不能部分覆盖。对应 N04–N06 / US-11–US-15、US-30。

## 三、配置入口与成片

F07：三张主线页顶部常驻“提示词配置”“系统配置”“风格模板”。配置在弹层内完成，关闭返回原步骤；逐环节入口默认选中对应步骤。保存到本浏览器演示空间，刷新可恢复；关闭未保存面板保留当前面板草稿，刷新不会保留未保存草稿。

F08：系统配置按剧本协作、分镜生成、分镜质检、台词、参考图、镜头提示词、风格推荐、模板建立、视频、配音、配乐、字幕分别配置服务商、服务地址、模型标识、能力、超时与凭据引用。原型只做格式校验，不进行连接测试，不输入或保存真实密钥。真实产品由服务端保护密钥。

F09：提示词中心提供系统默认和当前作品覆盖、变量说明、实际输入预览、恢复默认、显式保存。缺必填变量禁止保存。各环节的提示词入口使用同一份配置；更新仅影响新提交任务，旧任务快照保持不变。风格模板可新建、编辑、AI 辅助完善并选用，模板建立的提示词也可配置。对应 N07、N13、N14 / US-03–US-08、US-16。

F10：成片页展示镜头顺序、时长、配音/配乐方向和字幕开关；可预览分镜顺序，检查缺视频、分镜未确认、素材未确认及过期情况。上传视频可在分镜页播放；生成示例不是视频文件。导出只演示状态流转，制作清单 JSON 可真实下载，原型不伪造 MP4 文件。对应 N09–N11 / US-19–US-25。

## 四、JSON 交换与保存边界

建议采用“JSON + 明确结构约束 + 版本匹配 + 服务端原子更新”。请求携带 requestId、选定剧本 ID/版本、分镜版本、稳定镜头 ID、结构化台词/素材引用/提示词以及内容摘要；响应包含 schemaVersion、scriptId、baseBoardVersion、issues、proposedShots。JSON Schema 校验字段类型、必填项与允许字段；服务端再校验 ID 集合、版本和引用关系。版本不一致时让用户重新质检，不让 AI 自行合并冲突。

本原型采用完整 proposedShots 方便查看建议版，仅把允许的 dialogue/prompt 字段应用到原对象。真实接口如需修改多角色台词、情绪、素材引用，应显式扩展版本化结构并验证；不能直接将模型输出反序列化后覆盖整个项目。未来长分镜可使用按 shotId 列出的受限 changes，仍需生成完整预览，不能跳过校验或原子提交。

所有正式内容以工作区 Markdown、HTML、manifest 和标注文件为准。可交互作品状态使用独立键 `mengyuan-single-flow-demo-v2`，与 PRD 真相源分开；无真实服务调用。图片上限 2 MB、视频上限 3 MB 仅为本地演示限制，浏览器存储不足显示失败并保留当前页输入；不作为生产规格承诺。

## 五、视觉、状态与验收

默认深蓝工作台，保留浅/深主题按钮和跨页偏好；正文/输入/按钮 16px、辅助最低 14px。配置弹层、长文、表格均可滚动，不把剧本与分镜拼成长页。新增参考图见 `assets/user-storyboard-reference.png`。

公共状态页继续演示空状态、模型缺失、加载、审核失败、未确认、保存失败、局部重试、取消和上游过期。新主线另覆盖未选剧本、空备选、报告过期、JSON 拒绝替换、素材未确认和导出条件缺失。

本轮验收重点：多次生成 → 各自加入备选 → 选定终版 → 新页生成分镜 → 报告/建议版 → 一键采用 → 复检/确认 → 图片生成或上传/确认 → 镜头生成 → 成片页。另测三类配置、主题、刷新状态和过期报告拦截。完成情况由本轮浏览器检查记录补充；正式功能模块和真实服务接入尚未完成。

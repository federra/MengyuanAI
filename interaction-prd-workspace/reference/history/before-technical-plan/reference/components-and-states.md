# R2 主线原型与组件状态 · 五模块重构

本轮页面：项目；创意、故事、剧本、分镜、导出；资产；任务记录；系统设置；组件与状态展示。

## 演示路线

项目页创建作品 → 创意输入一句话 → 生成三份故事 → 故事页阅读/修改/再生成/翻历史 → 选定并生成剧本 → 右侧导演助手内一键修复与复检 → 确认分镜 → 采用质检建议 → 确认参考图 → TTS及顺序视频生成 → 导出制作清单。

已有故事在创意页上传TXT后进入故事工作台，左侧仅一张选题卡，正文完整保留。顶部五阶段允许浏览，生成仍检查依赖。主导航固定五项，设置集中管理模型、提示词、音频与风格。

## 组件与状态

公共组件：五模块侧栏、五阶段流程栏、项目卡与统计、三份候选分页器、正文编辑与AI侧栏、质检结论/修复差异、镜头表与图片引用、资产筛选卡、任务快照、配置弹窗、导出预览。

关键状态：无项目/空资产/无任务；输入为空/文件超限；候选选中/历史首尾；剧本生成/报告过期/修复；图片缺失/待确认；TTS过期；视频运行/失败/暂停/尾帧失效；导出阻断；配置变量错误/全局默认/项目覆盖。

## 原型与目标的区别

真实本地交互：项目和内容保存、文件导入、参考图上传、配置编辑、列表筛选、分页、稳定ID引用、制作清单下载。模拟：AI文本与质量结论、图像/音频/视频生成、服务连接与合成。任务日志记录演示快照，不伪称调用真实模型。

主模块规则见正式PRD 04–10；提示词工程清单见R4。视觉依据七张参考图的结构，不引入会员、机器人、账户权限或营销装饰。

新增公共组件：导演助手（固定、收起补位、悬浮、建议、待采用、已采用、过期拒绝）；生成操作行（主按钮、Skill/提示词、编辑）；项目筛选排序；全片元素管理弹窗；多角色台词列表。新增状态：TXT单卡、未设置画幅、参考元素变化、部分配音跳过、台词版本过期。

UI主题组件：右上角浅色/深色/晴空蓝三选一。品牌AI短片工坊。刷新记住选择；切换不丢失编辑内容，项目视频风格与UI主题互不影响。

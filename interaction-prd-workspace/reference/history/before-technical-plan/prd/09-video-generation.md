# 视频生成与任务记录模块

## 视频生成

前置条件为当前剧本有效、分镜质检确认、参考图确认、图片引用有效。支持独立镜头生成和按顺序生成。

顺序依赖：完成第 i 镜视频 → 提取该视频最后有效帧 → 将帧及来源视频版本传入第 i+1 镜 → 继续。前镜失败、尾帧为空或输入过期时停止后续提交。暂停保留已完成镜头，继续从未完成镜头开始。重做前镜时，依赖旧尾帧的后镜标记待更新。

每次任务冻结 projectId、shotId、源内容版本、模型配置、提示词版本、参考图版本及前镜来源。生成过程中修改系统配置不会改变已提交请求。上传视频可提取真实末帧；原型生成视频和对应末帧为标记清楚的示意内容。

## 任务记录

跨项目汇总每次 AI 调用：ID、项目、环节、发起/完成时间、状态、耗时、输入快照、输出/错误、关联内容版本。状态为排队、运行中、成功、失败、取消、因依赖暂停；真实服务需支持幂等任务提交和断线恢复。

列表支持状态筛选，详情显示当时的模型、提示词和结果。重试生成新记录并关联原任务，不改写原始失败。原型失败详情引导返回来源环节重试。

演示记录覆盖故事、剧本/质检、分镜/质检、参考图、TTS、视频和风格辅助。原型同步规则生成没有网络队列，运行中/取消等完整服务状态以状态展示和本节契约为准。遗留旧版本任务没有时间或状态时显示“已记录”，不伪造历史。

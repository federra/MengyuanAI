# 用户与需求分析

主要用户是梦源AI现有短片制作者，兼顾营销内容创作者和运营发布者。当前痛点是质检依赖外部 Web AI，多次复制上下文耗时，修复结果难以与版本对应。

| 需求 | 用户要完成的事 | 验收依据 |
|---|---|---|
| N01 项目连续性 | 找到并继续不同作品 | 项目数据隔离，进度来自当前内容 |
| N02 灵感探索 | 比较不同剧情方向 | 每次生成三份；历史不会被覆盖 |
| N03 原作改编 | 导入已有故事并保留其意图 | TXT经单选题卡进入共用剧本流程；不改写原始来源 |
| N04 人机编辑 | 围绕当前故事反复修改 | 修改版本独立，可切换其他候选 |
| N05 内置质检 | 原故事与剧本、剧本与分镜逐级核对 | 报告绑定输入版本；修改后失效并复检 |
| N06 可控镜头 | 修改台词、画面、引用与音频 | 单镜增删、排序；引用 ID 不依赖名称 |
| N07 连续画面 | 前镜尾帧参与后镜生成 | 逐镜依赖；失败停止，不跳镜 |
| N08 可复用资产 | 跨项目复用设定与素材 | 七种资产分类；引用记录资产版本 |
| N09 可追踪任务 | 知道何时、用什么、生成了什么 | 输入/模型/提示词/结果快照 |
| N10 可调配置 | 替换模型和定制提示词 | 全局默认与项目覆盖，变更只作用于后续任务 |
| N11 导出检查 | 调整节奏并交付作品 | 镜头顺序/时长、音轨与字幕设置、缺失检查 |
| N12 清晰界面 | 快速辨别位置和下一步 | 五模块、五阶段、少量主操作、双主题 |

中文/英文市场是目标输出语言与创作约束，不是权限或账户分组；导入中文故事到英文市场时，保留原文，改编输出按目标语言生成。

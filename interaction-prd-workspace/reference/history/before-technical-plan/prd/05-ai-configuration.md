# 系统设置模块

集中入口分为大模型、提示词、音频模型、风格模板四项。创作顶部保留一个提示词快捷入口，各环节可打开当前配置，避免堆满页面。

模型按环节配置 provider、model、endpoint、能力类型、超时和凭据引用；文本、图像、视频、音频分开。生产环境凭据保存在服务端安全存储，浏览器仅持 credentialRef。原型连接状态为模拟，不发真实请求。

提示词解析优先级：本项目覆盖 > 系统默认。Skill 与自定义文本均作为生成指令来源，记录名称与版本；不执行机器上的任意代码。必需变量缺失阻止保存，预览显示最终拼装内容。

风格模板包含名称、画面描述与可复用指令，支持新增和编辑。项目引用模板后生成任务冻结版本；模板更新标记依赖媒体需要检查，不静默覆盖已完成视频。

音频配置至少覆盖 TTS 模型、音色、语言、语速与情绪参数，配乐模型独立路由。声音资产不等同于模型配置：前者是可复用音色设定，后者负责服务连接。

首批提示词明细见 R4《AI 交互与提示词定制清单》。其中“待接入”项是目标规格，不代表所有模型任务都已在原型实现。配置变更保存版本，旧任务仍显示旧快照。

## 视频输出与导演提示词

系统设置增加视频输出默认设置，维护比例、分辨率与视频模型，按比例计算尺寸。新项目不写入画幅；第一次分镜设置时读取建议值并由用户确认，已有项目保持自己的规格。服务地址、供应商与凭据引用继续在模型配置中维护；任务快照必须反映项目实际选择的视频模型。

创意/故事/剧本/分镜导演助手分别使用独立修改指令；TXT选题提炼新增独立模板。完整28项见提示词清单。剧本与分镜质检仍独立于创作模型配置。写作、剧本和分镜方式均支持Skill或提示词，编辑入口与阶段主操作相邻；音频配置覆盖逐台词角色音色、语速和情绪。

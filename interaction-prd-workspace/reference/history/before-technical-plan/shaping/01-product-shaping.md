# 当前定型 · 五模块重构

最新范围以用户七张参考图及五模块要求为准。项目、创作、资产、任务记录、系统设置构成系统导航；创作按创意、故事、剧本、分镜、导出五阶段推进。一句话与TXT故事共用后续编辑器。

项目创建不预设画幅，也不设固定时长；画幅在分镜生成时设置；一句话故事候选三份一页并保留历史，TXT上传只提炼一个选题卡并保留全文。各工作台右栏为可收起的导演助手，剧本与分镜质检为常驻入口，分镜保留参考图、TTS和顺序尾帧生成。资产七类；任务追溯；提示词清单供工程师定制。双主题、可读中等字号、少量主按钮。

本批由用户明确授权整体实施，完成后统一评审。详情见正式PRD 01–10和R4；早期定型历史保存在reference/history。

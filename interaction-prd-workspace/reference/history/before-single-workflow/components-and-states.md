# 组件与状态参考

> G3 组件与状态审核稿 v1.0。DESIGN v1.0 已由用户确认；本页对应两张 1440 × 900 的独立参考原型。首版仅一句话/故事两主线，不包含参考视频、账号或权限模块。

## 一、公共页框与视觉约束

深色/浅色共用同一页框、布局和组件 ID，使用已确认色彩变量。顶部 64px、侧栏 208px、内容外边距 24px；正文及按钮 16px，辅助最低 14px，长文编辑行高 28px；控件最低 44px。窄窗口折叠导航并保持内容可滚动，不将文字整体缩小。焦点使用可见轮廓，原始素材颜色不随主题变化。

组件页和状态页作为参考演示，导航只在两页之间跳转；两页均是桌面原型，窄窗规则仅保证放大时可访问，不构成手机版交付。模型任务、质检、素材均是明确标记的示例，不使用真实密钥或外部调用。

## 三、状态语义与恢复

| 状态 ID | 场景与反馈 | 允许动作 / 验收 |
| --- | --- | --- |
| S01 | 初始空作品 | 创建示例后显示作品；不能用空白代替下一步提示 |
| S02 | 模型配置缺失 | 保留输入，明确阻断原因；本页可模拟补齐，不调用真实连接 |
| S03 | 素材生成成功 / 人工确认 | 生成结果与选用确认分开，点击确认后更新文字 |
| S04 | 排队 / 运行 / 部分失败 | 首次演示 3 镜头中 2 个成功、1 个失败，显示对应镜头与原因 |
| S05 | 仅重试失败镜头 | 成功镜头保持；重试成功后可继续选用，而不是标成整片已导出 |
| S06 | 取消处理中 / 已取消 | 先等待演示服务确认再标已取消；已成功成果保留 |
| S07 | 保存失败 / 离线 | 保留用户输入，模拟恢复连接后重新保存，不能在失败时显示已保存 |
| S08 | 上游已改 / 旧结果待更新 | 展示内容版本差异；不自动修改旧视频或提交重生成 |
| S09 | 加载 / 审核失败 / 内容待确认 | 状态对照分别说明原因、后续动作；无有效报告不能标通过 |

部分失败、保存恢复等可操作状态与静态状态对照同页呈现。页面未实现的业务能力以明确说明呈现，不做假跳转或调用浏览器 alert/confirm/prompt。

## 四、数据与演示边界

正式 PRD、页面和标注仍以工作区文件为准。主题偏好保存在浏览器 localStorage，仅影响界面；“保存演示草稿”写入独立命名的演示键，刷新可回读，恢复示例可清除。演示草稿不是项目数据、不会改写 PRD 文件。质检/提示词/任务演示为页面内状态，刷新恢复初始示例；所有提示清楚标记演示范围。

提示词面板本轮只校验两个演示必填变量，不代表完整变量解析器；真实保存提示词版本、默认/项目覆盖和调用结构将在 05 正式模块完善。进度使用短定时模拟，取消会终止待发生演示回调，防止取消后又跳到成功。

# PRD 板块计划

> 当前执行计划 v1.2｜2026-09-07。依据：用户已确认的 G0 v0.4 及用户新增的双主题、清晰字号要求和 MVP 两主线收敛决定。本计划固定为过程产物 `00`，不作为正式 PRD 导出；当前可见，G5 收口时隐藏并保留文件与历史。

## 一、交付顺序与边界

先交付 G2 三份基础分析 → G3 视觉规范、组件与状态参考 → G4 按下表逐模块交付 → G5 全局收口。正式 MVP PRD 共 10 个板块，其中 3 个基础板块、7 个功能板块；每个 G4 审核包只包含一个功能模块。

模型与提示词配置先于创作模块交付，保证每个 AI 步骤有统一配置来源；仅交付创意/故事两主线及共用制作链路，参考视频分支暂缓。质检集中定义故事对剧本、剧本对分镜两种审核目标。

首版 PC Web，默认 30–90 秒竖屏，包含两入口、内置质检、素材和视频生成、声音与基础剪辑、导出及两类配置。参考视频再创作、账号/用户权限/角色管理、团队协作、平台发布、运营分析、高级多轨剪辑和模板市场不在本期。现有梦源AI实现未经代码核验，本计划交付产品文档与交互原型，不承诺真实模型调用或现有系统改造已完成。

## 三、设计参考与模块交付要求

G3 先审核 `reference/DESIGN.md`：基于用户深蓝/灰蓝工作台参考制作深色方案，并补齐浅色方案；确认全局切换按钮、偏好保持、颜色、醒目适中的字号、布局、控件、焦点及可读性。再完善 `reference/components-and-states.md`、`components` 组件页与 `states` 公共状态页；参考资料不占正式 PRD 序号。原型候选固定视口为 1440 × 900，G3 确认后统一使用，视频竖屏画幅不等于移动端产品。

公共参考覆盖浅/深主题切换与配色、字号层级、导航/工具栏、表格、文本编辑、素材卡片、审核问题、修改预览、提示词设置面板、模型选择、版本标记、任务进度、音视频预览及反馈。新组件随所属模块补入公共参考，不提前实现所有功能。

每个功能模块交付：独立 Markdown、可操作主路径 HTML、专门的状态展示页（标记 state-gallery）、逐页 JSON 标注及关系更新。需求写明角色、前置、触发、规则、结果、异常和验收；标注优先锚定稳定元素 ID。原型共用 shared 样式与组件，不重写 runtime。

字体候选为正文/输入/表格/按钮 16px、辅助文字不低于 14px、区块标题 18–20px、页面标题 24–28px，G3 审核定稿。长文通过展开或滚动承载，不靠缩小字号增加密度。两主题共用页面与 ID，组件页、状态页展示两种主题；不为主题复制两套原型。

每轮运行 validate 并检查文档、原型、状态、标注、画布；在浅/深主题分别检查内容、弹层、加载/错误状态及文字可读性；关系先准确同步，再由底座自动排列。模块原型的实际点击与 manifest 关系一致。正式模块导出对应文档及稳定渲染后的原型截图，截图失败不算完整导出。原型试运行使用清楚标记的示例结果，不需要真实密钥，也不产生模型调用费用。

## 四、跨模块关系、依赖与待定细节

- **项目与创作入口：** 项目列表 → 项目概览 → 两入口；所有功能可回项目概览。
- **模型与提示词配置：** 全局入口 → 系统配置/提示词中心；各环节设置面板 → 中心 → 返回原环节。
- **创意引导与故事剧本：** 项目 → idea/story → script → review/storyboard；审核返回 script。
- **分镜与内置质检：** script → storyboard/review → style；问题定位回原内容；下游编辑返回同一分镜。
- **风格模板与参考素材：** storyboard → style ↔ style-template → assets ↔ asset-detail → video。
- **镜头视频与生成任务：** assets → video ↔ clip-detail → finishing；局部修改回 storyboard/assets。
- **声音、基础剪辑与导出：** video → finishing → export → 项目；发现问题回原镜头或素材。

共享规则归属：主题配色、字号和切换组件归 G3，全局入口及偏好保持归 04，所有模块复用；模型/提示词默认值、项目覆盖与调用快照归 05；剧本生成及编辑归 06；审核报告、确认版本和下游影响判定归 07，其他模块引用；素材模板与绑定归 08；视频任务与候选片段归 09；声音时间对齐和成片导出归 10。05 定义调用快照字段，07 定义内容变更的影响，09 定义视频任务运行状态，避免同一规则在多个模块产生不同版本。

06 在剧本页提供审核入口，完整审核工作台在下一模块 07 交付；06 审核包注明该交接尚待联调，不展示假已完成的跳转。任何目标页未交付时显示明确的待交付状态；目标模块交付后同步替换成真实链接，并回归前序模块。参考视频模块从本期目录和关系规划移除，资料作为后续方向保留；不在 MVP 界面放置禁用的第三入口。

尚待模块细化：05 确定模型能力/参数、变量与输出结构；07 明确阻断问题和用户保留意见规则；08 明确模板及素材引用；09 明确文件、时长、分辨率和并发限制；10 明确声音来源、字幕同步及导出参数。无具体供应商资料前不编造可用模型、额度、价格或性能承诺。涉及改变已确认范围的结论须回写定型记录。

## 二、用户故事与验收

下列“给定—当—则”分别对应前置情境、触发动作和可观察结果。验收覆盖正常与异常路径；供应商参数、严重度和视觉精确值仍按 01 的 D01–D06 在对应门禁定稿。

**US-01｜制作者创建作品并选择起点，以启动适合输入材料的创作路径**

需求：N01；模块：04；前置：已进入项目列表。

- 正常验收：给定空项目列表，当选择一句话/故事入口并创建时，则建立独立项目并进入对应输入页，展示默认目标参数。
- 异常验收：给定尚无素材或模型未配置，当创建项目时，则允许保存创作草稿，运行模型前给出配置入口，不以空白页面结束。

**US-02｜制作者保存并继续编辑，以保留阶段进度**

需求：N01；模块：04；前置：已有可编辑项目。

- 正常验收：给定已保存内容，当离开并重新打开项目时，则恢复最新保存版本、当前阶段及已关联成果。
- 异常验收：给定仍有未保存修改或保存失败，当离开页面时，则明确提示未保存状态并提供保留编辑/重试操作，不显示已保存。

**US-03｜使用者创建模型连接，以获得可用调用能力**

需求：N13；模块：05；前置：已打开当前工作区配置。

- 正常验收：给定服务地址、模型与所需凭据已填写，当执行连接检测时，则展示检测中和可用/失败结果，并保存连接信息。
- 异常验收：给定凭据无效或接口不可达，当检测失败时，则提供可理解原因与修改入口，反馈及导出不泄露密钥。

**US-04｜使用者按环节分配模型，以匹配生成和审核能力**

需求：N13；模块：05；前置：已有模型连接。

- 正常验收：给定适合的文本/图像/视频等能力，当为环节选择模型并保存时，则该环节显示所用连接、模型和参数；生成与审核可分别设置。
- 异常验收：给定环节未分配或模型能力不匹配，当提交任务时，则阻止无效调用并保留输入，允许返回配置修正。

**US-05｜使用者维护默认提示词，以统一后续调用方式**

需求：N14；模块：05；前置：选择了一个模型交互环节。

- 正常验收：给定该步骤默认提示词和变量说明，当编辑、预览并保存时，则形成可追溯默认版本，实际预览显示替换后的内容。
- 异常验收：给定必填变量缺失或模板无效，当准备试运行或保存为可用版本时，则指出错误位置和修复方式，不以可用状态启用。

**US-06｜制作者在环节内修改提示词，以调整当前作品**

需求：N14；模块：05；前置：项目有该环节及默认提示词。

- 正常验收：给定环节继承默认配置，当在就地面板修改并保存时，则标为项目自定义，默认配置及其他项目不变；恢复默认后重新继承。
- 异常验收：给定面板有未保存内容，当关闭或切换环节时，则提示保存或放弃；仅打开面板不触发模型调用。

**US-07｜制作者试运行提示词，以判断是否适合当前内容**

需求：N14；模块：05；前置：配置和输入通过基础校验。

- 正常验收：给定预览包含实际输入和生效配置，当主动试运行时，则显示试运行进度和候选结果，不自动替换正式剧本或素材。
- 异常验收：给定实际调用可能产生用量或试运行失败，当运行前/失败后查看反馈时，则分别看到用量提示/失败原因和重试入口，保留草稿。

**US-08｜制作者追溯任务配置，以解释结果差异**

需求：N06；模块：05/09；前置：存在已提交任务。

- 正常验收：给定任务按版本 A 提交，当随后保存版本 B 时，则新提交任务使用 B，已排队/运行任务和其结果仍可追溯 A。
- 异常验收：给定旧任务运行过程中输入或配置已变，当结果返回时，则标明所属版本，不覆盖新版本内容或冒充新任务结果。

**US-09｜制作者通过 AI 引导形成剧本，以展开一句话创意**

需求：N02；模块：06；前置：项目选择一句话入口。

- 正常验收：给定一句创意，当发起协作并回答必要追问时，则对话保留上下文，逐步形成可编辑剧本，确认前可继续调整。
- 异常验收：给定模型超时或内容不足，当生成无法继续时，则指出补充内容或重试路径，已输入的想法与对话保留。

**US-10｜制作者将故事转为剧本，以保留原作表达**

需求：N03；模块：06；前置：项目选择故事入口。

- 正常验收：给定故事文本和改编要求，当生成剧本时，则同时保留原文与剧本版本，能选定当前版本进入对照审核。
- 异常验收：给定故事为空或生成失败，当运行时，则要求补充或重试，不用空剧本替换原文或已有版本。

**US-11｜制作者在系统内发起对照质检，以省去外部粘贴**

需求：N04；模块：07；前置：已有来源和待审核内容版本。

- 正常验收：给定原故事对剧本、剧本对分镜的审核目标，当发起审核时，则自动带入依据与当前内容，报告区分遗漏、人物、情绪和动作等适用问题。
- 异常验收：给定来源缺失、版本未保存或报告结构错误，当准备审核或接收结果时，则提示修复，不显示通过；整个主路径无需复制至外部 Web AI。

**US-12｜制作者定位和处理审核意见，以有依据地修订内容**

需求：N04；模块：07；前置：存在有效审核报告。

- 正常验收：给定问题项包含依据及目标定位，当选中问题并预览修改时，则能查看对应原文/镜头与拟修改内容，采纳后形成内容新版本。
- 异常验收：给定问题指向的内容已被改动，当尝试采纳旧建议时，则标明报告过期并要求确认新内容/重新审核，不将修改套入错误位置。

**US-13｜制作者复检并确认当前内容，以进入下一阶段**

需求：N04；模块：07；前置：内容编辑完成。

- 正常验收：给定修改后当前版本，当发起复检并完成意见处理后执行人工确认时，则确认记录指向该版本，展示下一阶段入口。
- 异常验收：给定审核失败、仍存在必须处理的问题或确认后再修改，当尝试沿用旧确认时，则显示需处理或需重新确认；严重度/豁免细则在 07 定稿。

**US-14｜制作者生成并编辑分镜，以表达可制作的镜头**

需求：N05；模块：07；前置：剧本已确认。

- 正常验收：给定来源和当前目标，当生成分镜后编辑镜头时，则保留镜头 ID、顺序、时长、动作、情绪和素材引用，并能对照来源质检。
- 异常验收：给定已有参考图或视频，当再次编辑分镜时，则仍允许编辑保存，随后标记下游影响，不因已生成素材锁死脚本。

**US-15｜制作者查看修改影响，以选择必要的素材更新**

需求：N06；模块：07/08/09；前置：分镜或风格/参考素材已有下游引用。

- 正常验收：给定某镜头动作或素材发生改变，当保存时，则指出受影响的参考图/视频并提供查看、更新入口，旧版本保留可追溯。
- 异常验收：给定无关镜头不受此次修改影响，当更新受影响内容时，则不无提示地将全部成功素材重新生成；依赖边界在各模块细化。

**US-16｜制作者选择风格，以确定视觉制作方向**

需求：N07；模块：08；前置：分镜已确认。

- 正常验收：给定风格列表和分镜版本，当选择风格时，则显示当前选用风格并可进入参考素材制作；AI 推荐/描述优化有模型及提示词入口。
- 异常验收：给定已有素材且改选风格，当保存新风格时，则显示素材影响；普通手动选择不强制发起 AI 调用。

**US-17｜制作者建立自定义风格模板，以重复使用视觉要求**

需求：N07；模块：08；前置：可访问模板编辑入口。

- 正常验收：给定模板名称和风格描述，当手动编辑或使用 AI 辅助后保存时，则形成可选择复用的模板版本，并能应用到当前项目。
- 异常验收：给定 AI 辅助失败或模板必要内容缺失，当保存/生成时，则保留手动内容并提示修复；AI 内容须可编辑后再保存。

**US-18｜制作者准备并绑定参考图，以控制角色与画面关系**

需求：N08；模块：08；前置：存在分镜和风格。

- 正常验收：给定角色/场景/道具/站位需求，当生成或选用参考图并绑定镜头后确认时，则能从镜头查看对应素材，只有用户选用的版本进入视频输入。
- 异常验收：给定参考图生成失败或缺少所需绑定，当准备生成视频时，则定位缺失素材并允许局部补齐，不把候选图自动标为已确认。

**US-19｜制作者生成和选择镜头视频，以获得可用片段**

需求：N09；模块：09；前置：目标镜头所需分镜、风格、素材和配置已就绪。

- 正常验收：给定确认的输入版本，当提交镜头生成时，则显示排队/进度/成功结果，能预览候选并明确选入成片。
- 异常验收：给定模型能力不支持输入或某镜头失败，当查看任务时，则标明原因与对应镜头，不以空视频占位为成功。

**US-20｜制作者恢复失败任务，以保留已完成镜头**

需求：N09；模块：09；前置：一次生成存在失败镜头。

- 正常验收：给定部分镜头成功，当重试失败镜头时，则保留成功候选，重试作为新提交任务显示实际生效配置与输入版本。
- 异常验收：给定运行中请求取消，当服务尚未确认停止时，则展示取消处理中或能力限制，不立刻宣称已取消；已返回成功结果仍可追溯。

**US-21｜制作者配置配音，以表达对白或旁白**

需求：N10；模块：10；前置：存在文本及可预览镜头。

- 正常验收：给定可用的配音方式和对应文本，当生成/选择配音并预览时，则能听到与目标片段关联的声音并调整选用结果。
- 异常验收：给定配音失败或文本修改，当查看片段时，则显示失败或需要更新，不误用旧音轨作为新文本的完成结果。

**US-22｜制作者校对字幕，以使文本与声音画面一致**

需求：N10；模块：10；前置：已准备字幕文本或可生成的内容。

- 正常验收：给定字幕内容和对应片段，当编辑文字及时间后预览时，则按选定位置和时间展示当前字幕。
- 异常验收：给定镜头顺序/时长改变，当字幕引用可能不同步时，则提示检查受影响字幕，导出前能重新预览而非静默沿用错误时序。

**US-23｜制作者设置配乐，以补充成片情绪**

需求：N10；模块：10；前置：成片有可预览片段。

- 正常验收：给定可用配乐来源，当选择并调整使用范围/音量后预览时，则可听到当前配乐与配音组合；来源及能力在 10 细化。
- 异常验收：给定配乐加载或生成失败，当预览/导出检查时，则给出替换或重试入口，不伪造可播放结果。

**US-24｜制作者调整镜头顺序与时长，以形成成片节奏**

需求：N10；模块：10；前置：已选择镜头视频。

- 正常验收：给定镜头列表，当调整顺序或在支持范围内修改时长时，则更新成片预览并提示检查受影响声音和字幕。
- 异常验收：给定时长修改超出片段或工具能力，当操作时，则明确边界并给出修复选择，不无提示拉伸或截断重要内容。

**US-25｜制作者导出成片，以获得可交付视频**

需求：N11；模块：10；前置：成片已预览并准备导出。

- 正常验收：给定素材完整且影响项已处理，当提交导出时，则显示进度、绑定成片版本并在成功后提供可下载文件。
- 异常验收：给定缺失镜头、过期素材未确认或导出失败，当检查/合成时，则定位问题并允许修复或重试，保留剪辑和声音结果。

**US-28｜制作者切换主题并清楚阅读，以适应编辑环境**

需求：N15；模块：G3/04；前置：处于任一产品创作或配置页。

- 正常验收：给定当前主题与未保存输入，当点击浅/深切换按钮时，则界面更新、输入及任务状态保留，跨页/刷新保持选择，媒体本身颜色不变。
- 异常验收：给定长剧本、提示词、错误状态或页面放大，当阅读操作时，则两主题文字清晰、可展开或滚动，关键按钮可访问，不靠过小字号压缩内容。

## 三、现状与目标旅程

现状可确认部分如下。用户未描述的写作、素材、剪辑详细过程不作为事实填充；“挫败”“焦虑”等情绪没有直接陈述，不编造情绪曲线。

| 现状阶段 | 用户动作/触点 | 事实或推断 | 痛点与机会 |
| --- | --- | --- | --- |
| 制作内容 | 使用自研梦源AI，具体生成过程未提供 | E04 用户自述 | 需与已有工作习惯衔接 |
| 准备质检 | 人工将需审核内容粘贴到外部 Web AI | E04 已知，具体次数未知 | 用系统自动带入上下文替代搬运 |
| 获取审核意见 | 在外部 AI 对话中完成质检 | E04 已知，时长未测 | 在项目中展示问题、来源及目标位置 |
| 修订并继续 | 具体回写和生成方式未提供 | “需要把意见用于制作”是任务推断 | 修改预览、复检及版本追溯有待试用验证 |

目标旅程中的生成、审核和运行反馈为产品设计；阶段等待时显示进度/原因和可恢复操作，用户感受是否改善通过试用验证。

| 阶段 | 用户动作与产品响应 | 页面/故事/模块 | 成功信号 |
| --- | --- | --- | --- |
| 开始及设置 | 建项目选入口；运行前查看配置完整性，按需调整模型/提示词 | projects / US-01–US-08 / 04、05 | 输入可保存，调用配置和生效范围明确 |
| 创意路径 | 一句话 → 多轮引导 → 可编辑剧本 → 审核/用户确认 | idea、script、review / US-09、US-11–US-13 / 06、07 | 形成确认剧本，意见可定位处理 |
| 故事路径 | 输入原故事 → 改编剧本 → 对照原文审核/修订/确认 | story、script、review / US-10–US-13 / 06、07 | 原文保留，人物/剧情差异得到处理 |
| 共用分镜与审核 | 两条路径均把剧本转分镜并对照审核，随时编辑并处理影响 | storyboard、review / US-11–US-15 / 07 | 当前分镜版本经用户确认，旧报告不混用 |
| 视觉素材 | 选风格/建模板 → 生成并绑定参考图 → 用户确认 | style、style-template、assets / US-16–US-18 / 08 | 镜头引用素材清楚且选用版本确定 |
| 视频制作 | 提交镜头任务 → 预览/选择候选 → 局部失败恢复 | video、clip-detail / US-19、US-20 / 09 | 已选镜头可供成片使用 |
| 成片交付 | 配音/字幕/配乐、排序/时长调整 → 预览 → 导出 | finishing、export / US-21–US-25 / 10 | 音画可检查，导出对应成片版本且可下载 |
| 随时调整 | 切主题、调提示词、保存项目或修订上游内容 | 全局及就地面板 / US-02、US-06、US-08、US-15、US-28 | 编辑状态保留，影响范围和配置版本清楚 |

## 四、失败、退出与恢复

| 场景 | 反馈与允许操作 | 恢复去向 / 故事 |
| --- | --- | --- |
| 未保存退出、离线或保存失败 | 区分编辑中与已保存；保留内容并提示重试/返回编辑，不能假称已落盘 | 原项目原内容 / US-02 |
| 缺失模型、能力不匹配、模板变量错误 | 在调用前定位配置问题；从环节进入配置并返回，保留输入 | 当前调用步骤 / US-03–US-07 |
| 生成超时、无效审核报告 | 不标记成功或通过；显示原因并允许重试，保留来源与已有结果 | 剧本/审核页 / US-09–US-13 |
| 旧报告建议与新内容冲突 | 显示已过期；对当前内容重新审核，禁止无提示套用 | 当前版本审核 / US-12、US-13 |
| 上游修改使下游待更新 | 显示对应素材/镜头及原因，选择局部更新或明确保留旧引用，导出前检查 | 分镜/素材/镜头 / US-15、US-25 |
| 视频部分失败、取消未完成 | 保留成功候选，单独重试失败项；取消未确认则展示实际状态 | 镜头任务 / US-19、US-20 |
| 变序或变长导致字幕/音频可能失配 | 指出受影响内容，重新调整和预览 | 成片编辑 / US-21–US-24 |
| 导出失败 | 重试合成或定位缺失素材；不清空已保存成果 | 成片导出 / US-25 |

“保留旧引用”是可追溯选择，不等于消除过期标记；当导出检查发现未处理影响项时，需要用户处理后才继续。问题严重度与是否可豁免仍以 07 正式规则为准。

## 五、后台支撑与审核交接

首版不设计账号、角色、用户权限或跨人员审批流程。下表描述系统支撑责任，不新增未确认的用户角色。

| 前台动作 | 系统支撑 | 必要交接与约束 |
| --- | --- | --- |
| 提交模型任务 | 解析环节绑定、能力校验、替换变量、保存调用快照 | 内容/模型/提示词版本、参数及素材引用；密钥仅引用，不写入内容快照 |
| 请求质检 | 组合对照来源、接收结构化问题、核对内容版本 | 明确目标是原故事对剧本，还是剧本对分镜；格式错误与过期报告不算通过 |
| 保存上游变更 | 建新版本、定位下游依赖、展示影响 | 不覆盖旧任务及结果；任务回包属于提交时版本 |
| 生成及导出 | 记录进度、结果/失败、候选与选用关系 | 具体并发、超时和文件规格按确定的服务能力设置，无假定时限承诺 |
| 切换主题 | 更新界面偏好、保留当前编辑和任务状态 | 仅改变产品界面，不改媒体及成片颜色；精确视觉规范由 G3 审核 |

本文件与 01/02 已按用户“基本同意”及两主线补充更新，通过 G2，进入 G3 设计基线。后续 04–10 将故事进一步拆成原子功能、字段、状态页、标注和真实跳转；现阶段三个基础模块没有产品原型，其导出仅为文档。

# 产品定型

当前有效范围：用户在 G2 审核时明确收敛 MVP 为两条主线，优先于历史三入口规划。正式定义见 PRD 01，版本为 G2 v1.1。

梦源AI 为短片制作者提供“一句话创意到短片、故事文本到短片”的 PC Web 工作台，优先解决质检需要复制至外部 Web AI 的耗时问题。营销和剧情短片均支持，默认 30–90 秒竖屏。

两入口共用剧本与分镜编辑、内置对照审核、风格及模板、角色/场景/道具/站位参考图、视频生成、配音/字幕/配乐、基础剪辑和导出。模型按环节配置，提示词中心维护默认版本，环节入口编辑项目覆盖。

用户权限、账号和角色管理、团队协作、参考视频再创作、发布运营及高级剪辑暂缓。项目仅用于创建、保存和继续作品；配置只保留主线运行需要的模型与提示词工具。

视觉按用户参考建立深色及浅色主题，全局按钮切换；字体清楚适中。G2 已按补充要求通过，G3 的具体视觉基线待审核。

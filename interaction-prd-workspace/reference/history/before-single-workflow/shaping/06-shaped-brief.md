## v0.1 候选摘要｜2026-09-07｜待澄清，未通过 G0

产品定位：为短视频创作者、发布者与运营者，把创意、故事或参考视频转为可编辑、可审核的 AI 短片，提升生产效率与质量。

目标用户与场景：一句话创意展开、故事改编、参考视频分析与再创作；前端入口不同，分镜之后共用风格、参考图、镜头视频与导出链路。

已确认的首版范围：PC Web，三入口，剧本和分镜编辑、交叉审核、风格及自定义模板、角色/场景/道具/站位参考图、镜头生成、整片预览与导出；暂缓团队协作、平台发布和运营分析。

已确认的控制方式：用户确认剧本、分镜和参考图；AI 审核提出修改建议，修改后可重查；上游改动提示下游素材影响。分镜随时可编辑为原始明确需求。

补充建议：审核问题提供证据；生成任务绑定输入版本；局部失败可单独重试。路径三以用户意图和选定借鉴点为审核依据，以上在 G0 摘要确认时一并审核。

视觉基线：用户已有规范或参考，稍后提供；不采用默认方案。

待确认：目标成片类型/时长、音频字幕与基础剪辑范围、现有流程及角色；等待用户提供视觉规范。具体问题见“待确认问题”。

审核说明：本稿供讨论，不是正式 PRD 或已批准设计；问题收敛后追加可供 G0 审核的定型版本。

## v0.2 定型候选｜2026-09-07｜待视觉输入与 G0 确认

**产品定位：** 梦源AI 为短片制作者提供从想法、故事、参考视频到成片的创作工作台；优先将当前需要外部 AI 复制粘贴的质检内置，提高审核和修订效率。现有系统基本可用来自用户自述，尚未核验实现。

**用户与成片：** 营销视频和剧情短片的制作者、发布者及运营者；首版 PC Web，默认 30–90 秒竖屏。

**首版范围：** 三入口 → 剧本/分镜生成与对照审核 → 风格及自定义模板 → 角色/场景/道具/站位参考图 → 镜头视频 → 配音/字幕/配乐、顺序与时长调整 → 预览与导出。竞品入口先拆解与分析，再结合自己的想法或参考图生成新分镜。

**控制与质量：** 剧本、分镜、参考图由用户确认；分镜随时可编辑；AI 提供修改建议并可复检；上游改动提示下游影响。补充规则建议为审核证据定位、版本绑定、修改预览与局部重试，待整版 G0 确认。质检耗时与跨工具复制次数作为首要测量候选，目标值待基线测量。

**边界与视觉：** 暂缓团队协作、平台发布、运营数据分析；建议暂缓高级多轨剪辑和模板市场。用户已有视觉规范或参考，等待提供后登记；不预设产品视觉样式。

**审核状态：** 上述用户答复已同步；本候选尚未整版通过 G0。收到视觉输入并取得明确确认后，进入 G1 板块计划。

## v0.3 产品定型审核稿｜2026-09-07｜待 G0 明确确认

**定位与优先问题：** 面向短片制作者及营销、内容运营人群，提供从创意到导出成片的梦源AI工作台；优先解决目前把剧本或分镜粘贴至外部 Web AI 质检的耗时，实现系统内对照审核、定位、修改和复检。现有系统基本可用为用户自述，尚无代码核验。

**首版范围：** PC Web，营销与剧情短片均支持，默认 30–90 秒竖屏。三条入口为“一句话 → AI 多轮剧本协作”“故事 → 剧本及原文贴合审核”“参考视频 → 分镜拆解和结构洞察 → 结合自身想法/参考图创作新分镜”；随后共用分镜编辑与质检、风格和自定义模板、角色/场景/道具/站位参考图、镜头视频、配音/字幕/配乐、镜头顺序和时长调整、预览与导出。

**控制与业务规则：** 剧本、分镜、参考图由用户确认；分镜随时可编辑，上游改动提示下游影响。建议审核问题提供定位与依据，支持修改预览、采纳和复检；输入版本绑定输出，部分失败局部重试。路径三检查用户意图及选定借鉴点，不把复刻竞品剧情作为通过条件。以上补充规则纳入本次 G0 审核。

**数据、权限与边界：** 建议首版项目由所有者编辑、确认、生成和导出，记录来源、剧本/分镜版本、审核记录、风格、素材、任务与成片引用。暂缓团队协作、平台发布及运营数据分析；建议暂缓高级多轨剪辑与模板市场。首要测量候选是质检人工耗时与跨工具复制次数，数值目标待基线测量；供应商和参数限制在相应模块细化。

**视觉输入：** 采用用户提供的角色设置截图，沿用深蓝底色、灰蓝面板、浅色文字、紧凑工具栏、表格式素材管理与描边控件。截图已保存，参考依据见 DESIGN；精确 tokens、公共组件和状态规范在 G3 审核。截图中的功能不自动新增到本期范围。

**审核请求：** 请确认 v0.3 是否作为后续交互 PRD 的基础版本。确认后进入 G1 板块计划；当前尚未通过 G0。

## v0.4 产品定型审核稿｜2026-09-07｜待 G0 明确确认

**产品与范围：** 梦源AI 面向短片制作者及营销、内容运营人群，首版 PC Web 支持营销和剧情短片，默认 30–90 秒竖屏。三条入口为一句话创意引导、故事改编、参考视频拆解与再创作，共用剧本/分镜审核和编辑、风格及自定义模板、角色/场景/道具/站位参考图、镜头生成、配音/字幕/配乐、顺序与时长调整、预览与导出。优先内置质检，减少复制内容到外部 Web AI 的耗时。

**新增明确需求：** 增设系统配置页，为各模型调用环节配置模型信息；所有模型交互步骤支持自定义提示词，包括质检、图像生成、AI 风格处理、AI 模板建立、视频生成及其他实际调用模型的步骤。

**配置方案建议：** 系统配置集中维护模型连接、能力、参数与环节分配，生成和质检可用不同模型。提示词中心维护默认版本，各环节提供就地编辑入口并默认仅修改当前项目；两入口共用配置，显式设置为默认后才影响其他继承默认的后续任务。支持变量说明、实际输入预览、试运行、版本记录及恢复默认；手动选择风格等非模型操作无需提示词。

**控制与生效规则：** 剧本、分镜、参考图由用户确认；分镜随时可编辑，上游修改提示下游影响。建议审核问题提供定位和依据，修改可预览、采纳并复检；生成任务绑定内容、模型和提示词版本，局部失败可重试。配置修改仅对新提交任务生效，已排队/运行任务和已完成结果不自动更新；无效连接、能力不匹配或缺失提示词变量应在调用前提示修复。

**数据、权限与边界：** 保存来源、内容与审核版本、风格素材、模型连接、环节绑定、提示词默认版本/项目覆盖及任务引用；凭据掩码展示、快照不含密钥明文。建议单使用者工作区由配置所有者管理默认配置、项目所有者编辑和导出；多人部署权限在配置模块定稿前细化。暂缓团队协作、平台发布、运营分析，建议暂缓高级多轨剪辑与模板市场。首要测量候选为质检人工耗时与跨工具复制次数，目标值待基线测量。

**视觉与审核：** 沿用用户角色设置截图的深蓝底色、灰蓝面板、浅色文字、紧凑工具栏和描边控件；具体设计规范在 G3 审核。请确认 v0.4 是否作为后续交互 PRD 的基础版本；确认后进入 G1 板块计划。

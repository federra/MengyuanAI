# MVP 范围

当前基线：G2 v1.1 / 计划 v1.2，按用户最新范围补充执行。

## 做

PC Web，两条工作流：一句话到短片、故事到短片。共用剧本/分镜编辑与内置质检、风格及自定义模板、参考图、镜头视频、配音/字幕/配乐、顺序/时长调整、预览导出。

保留必要支撑：作品创建/保存/继续，模型按环节配置，提示词中心与就地项目覆盖，输入及任务版本追溯，局部失败恢复，浅/深主题切换与清晰字号。

## 暂缓

参考视频上传/拆解/再创作；账号、角色和用户权限管理；团队协作、平台发布/排期、运营分析、高级多轨剪辑及模板市场。不训练基础模型。原先参考视频需求保留在后续资料，MVP 不展示第三入口。

## 规则与测量

剧本、分镜和参考图由用户确认；分镜随时可编辑，上游改动提示下游影响。模型与提示词版本对新提交任务生效，进行中任务保留原输入；成功成果不被重试无提示覆盖。

质检目标是系统内完成，主路径无需外部复制；效率与质量数值待实测。正式业务约束、指标口径和未决项见 PRD 01；本期不再将权限问题作为模块前置。

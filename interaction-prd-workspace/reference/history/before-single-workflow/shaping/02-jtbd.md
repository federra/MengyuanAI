# 用户任务与动机

已知：主要使用者是短片制作者，当前使用基本可用的自研梦源AI；质检要复制内容至外部 Web AI，耗时。具体复制次数、审核准备与回写时长未测。

核心任务：当剧本或分镜准备好时，在项目内完成对照质检、问题定位、修订与复检，从而减少上下文搬运。只有一句创意时，需要 AI 追问协助写成剧本；有故事时，需要保留剧情与人物并转成可制作分镜。

功能进展是获得可预览导出的短片；控制感、降低焦虑和按期交付是需求推断，尚未访谈验证。参考视频学习任务按最新 MVP 决定暂缓。

专业调优需要能修改模型及提示词；恢复能力需要保存作品、保留成功素材和标明上游变更的影响。无需先完成账号、角色或权限模块即可演示主线。

正式需求见 PRD 02：14 项有效需求，N12 暂缓且编号保留；验收故事见 PRD 03。

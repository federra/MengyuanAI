# 资产模块

统一管理角色、场景、道具、服饰、站位图、风格模板、声音七类资产。列表支持类别筛选、名称/描述搜索、新建、编辑和用于当前项目。

资产通用字段：assetId、类别、名称、描述、版本、预览、来源与更新时间。图片类支持 PNG/JPEG/WebP；原型单图2MB。声音包含音色引用/语言/表现参数；风格包含可复用视觉约束，真实媒体上传与声音试听由后续服务接入。

复用采用版本快照：从库加入当前项目后，在分镜参考图详情选择。保留镜头内部 assetId，同时记录 libraryAssetId 和 libraryVersion，避免破坏提示词绑定。库中编辑不静默改变已有项目素材，需要用户主动采用新版。

系统设置保存的风格同步到资产库；资产库新增或编辑风格也更新系统模板。项目按模板索引选用；正式实现应将索引升级为稳定模板ID，避免模板删除或重排造成引用漂移。

验收：创建图片资产 → 加入项目 → 分镜选择 → 提示词标签打开相同图片；重命名或库中编辑不会错绑到同名素材。空状态给出新增入口，不展示虚构资产数量。

# 用户故事与旅程

## 两条主线

一句话：项目 → 创意输入与写作指令 → 三个故事候选 → 选择/修改故事 → 剧本生成与自动质检 → 修复并复检 → 分镜生成与质检 → 参考图与 TTS → 视频 → 导出。

已有故事：项目 → 创意页导入 TXT 或粘贴 → 剧本生成与自动质检 → 共用分镜与导出。故事阶段可回看原始内容，不强制生成三个替代原作。

## 关键用户故事

| 编号 | 行为 | 结果与异常 |
|---|---|---|
| US01 | 创建项目并选择市场和风格 | 名称必填；类型可扩展；无时长表单 |
| US02 | 输入一句话并生成 | 三个剧情方向不同的候选；失败保留输入 |
| US03 | 生成更多与翻历史 | 每次新增三份，最新在前，每页三份 |
| US04 | 阅读候选并多轮修改 | 只更新当前候选，保存旧版本 |
| US05 | 选定故事并生成剧本 | 冻结故事版本，自动质检 |
| US06 | 应用质检修复 | 原版保留，报告作为上下文，产出新版并复检 |
| US07 | 编辑分镜 | 增删排序后质检失效，受影响媒体待更新 |
| US08 | 点击提示词中的图片引用 | 打开精确对应的图片，而非同名近似匹配 |
| US09 | 顺序生成视频 | 前镜完成并得到末帧后才能提交后镜 |
| US10 | 从资产库复用素材 | 复制指定版本到项目；不会静默更新既有成片 |
| US11 | 查看失败任务 | 可追溯错误和配置，返回来源环节重试 |
| US12 | 调整剪辑与导出 | 缺失/过期镜头阻断导出；清单可真实下载 |

## 跨阶段规则

顶部阶段可自由查看，执行下一阶段仍受前置确认约束。更换故事不静默删除既有分镜，旧结果保留但标记过期；未通过当前版本质检不能确认新剧本。项目切换不混入其他项目文本、任务和镜头。

# 创作模块：分镜与质检

分镜为独立阶段页，不与故事/剧本拼成超长页。表格字段为序号、台词、角色/场景/道具/站位图、提示词、视频、音频TTS、操作。大表局部横向滚动，保持文字可读。

台词与提示词支持人工编辑；参考图支持 AI 示例生成、上传、项目资产引用和确认。站位图与其他参考图共同作为视频输入。服饰可通过资产设定参与角色参考，首版核心必需参考仍为四类。

分镜支持向下新增、删除、上下移动。镜头 ID 稳定，序号只表示当前排序。图片引用存储为稳定 assetId，渲染为可点击标签；名称变化不破坏绑定，删除或错误 ID 必须阻止提交。

质检输入为已确认剧本及当前分镜 JSON；检查信息遗漏、情绪错位、动作逻辑与场景连续性。输出 schemaVersion、scriptId、baseBoardVersion、issues、proposedShots。客户端校验 JSON Schema、镜头 ID 集合、引用集合和基准版本后才可应用。

采用建议版前归档原表；一键替换后复检。报告过期或结构错误时保留原表并说明原因，不能部分写入造成混版。编辑上游内容后标记受影响视频/音频/尾帧引用过期。

台词 TTS 独立生成和重试，快照包含台词、音色、语言、模型与提示词版本。修改台词使旧音频过期。浏览器朗读仅是预听交互示例，不等于真实 TTS 模型文件。

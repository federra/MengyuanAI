# 产品定义与目标

梦源AI 是面向短片制作者的 PC Web 创作系统，帮助营销视频和剧情短片创作者把创意或已有故事转成可制作的镜头和成片。优先解决现有梦源AI需要人工复制到外部 AI 对话进行质检的问题，把生成、检查、修复和版本追踪留在同一工作空间。

## 产品结构

左侧固定五个模块：项目、创作、资产、任务记录、系统设置。创作包含顶部五个阶段：创意 → 故事 → 剧本 → 分镜 → 导出。两条入口共用后续阶段，不建立两套编辑器。

项目设置名称、可扩展类型、中文/英文市场、视觉风格和画幅。创建阶段不设置固定时长；故事可按内容估计时长，最终时长以分镜及剪辑累计为准。默认竖屏 9:16。

## 首版范围

包含项目隔离、三份故事候选及历史分页、故事对话修改、剧本自动质检与修复、分镜编辑与质检、四类核心参考图、独立 TTS、视频顺序生成、基础剪辑与导出、资产复用、任务追踪、模型/提示词/风格配置。

不包含权限体系、团队审批、订阅计费、平台发布、运营分析、竞品视频仿写。截图中的机器人、会员推广和个人账户不作为本期功能。完整专业时间轴编辑、剪映工程兼容为后续能力，不将示意按钮当作已实现服务。

## 成功标准

验证用户无需往返外部对话即可完成两次质检；记录每个阶段耗时、质检后返修次数、人工修改比例和成片完成率。上线前采集现有流程基线，再确定改善目标；原型不展示虚构增长数据。

## 原型边界

当前交付为本地可交互 PRD：数据在浏览器保存，AI 输出、TTS、视频与合成采用明确标识的示例。TXT 和图片上传、配置编辑、项目切换、历史记录、制作清单 JSON 下载是真实本地交互。目标产品的真实 AI 与编码服务仍需开发接入。

# 项目模块

项目页由宽标题、四个统计指标、项目记录和创建表单构成。指标为项目总数、创作中、完成、失败任务数，不展示无来源的增长百分比。

创建字段：名称（必填，最多50字符）、类型（营销短视频/通用短视频/剧情短片，可增加且去重）、市场（中文/英文）、风格模板、画幅（9:16/16:9/1:1）。不设置固定时长。风格管理跳转系统设置。

每个项目有稳定 projectId、名称、类型、市场、更新时间、独立创作状态。卡片展示当前阶段，继续创作激活对应项目。首次升级将既有单项目导入项目库，保留原始存储作为迁移备份。

验收：创建两个项目后分别编辑故事，切换仍保留各自内容；项目名称不因选定故事标题而改变。所有异步任务按发起时 projectId 写回；切换项目后不得把结果写入当前项目。

原型页：projects。空库、名称空白、扩展类型、当前项目、草稿/分镜/完成状态为关键状态。统计完成在真实导出完成后更新；演示导出不得宣称生成真实文件。

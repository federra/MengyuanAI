# 用户与需求分析

> G2 基础修订 v1.3｜依据 01 的 E01–E10。当前恢复 N03；仅 N12 参考视频再创作延期。以下 14 项是本期 P0 需求，不代表全部已有真实实现。

## 一、使用者与现状

主要实际操作者是短片制作者，承担文本、镜头、素材、声音和成片决策；营销创作者及发布运营者可作为内容生产者使用同一工作台。首版无需独立账号、审批或权限角色。模型和提示词设置是制作者的工具配置任务。

已知现状：梦源AI基本可用，质检仍需手工复制到外部 Web AI。审核准备、回写耗时及模型成本尚未实测。减少上下文搬运、明确返工范围是设计目标；用户对质量、成本或等待的具体容忍度仍需试用验证。

## 三、使用约束

首次使用应看清当前阶段与一个主要动作，高级配置折叠但随时可达。小说、剧本和分镜各在独立页面/弹层承载，避免长页混排。正文 15px，长内容展开或局部滚动；深浅主题保持输入、焦点和反馈可读。

弱网或保存失败必须保留编辑并给出重试；生成失败不清空已完成镜头；前镜失效后明确后镜需更新。原型只验证本地保存和示例状态，真实服务恢复策略仍需接入测试。

发布排期、运营分析、团队审批、高级剪辑和模板市场均不在本期。购买者、客户审片人或观众行为尚无独立证据，不据此新增管理模块。

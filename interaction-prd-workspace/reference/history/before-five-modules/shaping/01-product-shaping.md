# 产品定型

> 2026-09-07 当前有效修订，依据用户最新明确指令。

PC Web；一句话和小说/故事两条入口，共用剧本、分镜、参考图、视频、成片页。默认 60 秒、9:16，可选 30/90 秒、16:9/1:1。暂不做参考视频再创作、账号权限、团队协作、发布运营、高级多轨剪辑。

已知优先问题是质检内容在梦源AI与外部 Web AI 之间人工搬运。方案在小说→剧本与剧本→分镜两次自动对照，带报告修复并复检，再由用户确认。一句话 + 写作 skill / 提示词 → 三个小说选题 → 小说详情与多轮修改 → 选定小说 + 剧本 skill / 提示词 → 剧本 → 自动质检与修复 → 确认 → 分镜 → 自动质检与修复 → 四类参考图 → 独立 TTS / 视频 → 成片与导出。小说入口直接从原文与剧本指令进入共用剧本页。

原型用于验证操作，不承诺真实 AI 质量或已有系统已改造。

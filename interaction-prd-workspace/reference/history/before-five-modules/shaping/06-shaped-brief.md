> 当前有效 v0.6｜2026-09-07；本轮直接工作流修改指令覆盖此前单入口要求，不重新追问已确认事项。

PC Web；一句话和小说/故事两条入口，共用剧本、分镜、参考图、视频、成片页。默认 60 秒、9:16，可选 30/90 秒、16:9/1:1。暂不做参考视频再创作、账号权限、团队协作、发布运营、高级多轨剪辑。

一句话 + 写作 skill / 提示词 → 三个小说选题 → 小说详情与多轮修改 → 选定小说 + 剧本 skill / 提示词 → 剧本 → 自动质检与修复 → 确认 → 分镜 → 自动质检与修复 → 四类参考图 → 独立 TTS / 视频 → 成片与导出。小说入口直接从原文与剧本指令进入共用剧本页。

质量检查分别覆盖小说→剧本的剧情/情绪贴合与自身连贯性，以及剧本→分镜的遗漏/情绪/动作逻辑。报告简短可修复，修复带入报告上下文，复检后人工确认。分镜新增站位图、独立 TTS、增删镜头、准确 @图片预览和尾帧顺序生成。

视觉沿用深蓝参考并提供浅色，正文从 16px 调整为 15px，顶部只留配置和主题，低频动作折叠。R2 本轮修订可操作；G4 正式模块与真实服务实现不自动标为完成。

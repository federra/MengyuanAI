# 页面与流程

一句话 + 写作 skill / 提示词 → 三个小说选题 → 小说详情与多轮修改 → 选定小说 + 剧本 skill / 提示词 → 剧本 → 自动质检与修复 → 确认 → 分镜 → 自动质检与修复 → 四类参考图 → 独立 TTS / 视频 → 成片与导出。小说入口直接从原文与剧本指令进入共用剧本页。

creation：类型和规格、输入、指令选择、三选题卡、小说详情弹层及新选题要求。script：来源小说、剧本编辑与指令、自动质检、修复、确认。storyboard：独立表格、质检弹层、四类参考图、图片引用、独立 TTS 和视频任务。finishing：顺序/时长、声音/字幕、预览与导出。

各页共享顶部四步导航与「配置」弹层。提示词、模型、音频模型、风格模板统一入口；不增加常驻按钮。后半程页面和状态由两条入口共同使用。

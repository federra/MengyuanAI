# V13 分镜交互与整表导入

2026-09-10。本轮只修改交互PRD/Demo与技术规划，未改生产服务或数据库、未调用付费模型。

## 一、交互变更

- 移除单独TTS列；每句台词底部固定小入口独立生成、重做和试听，其他句为空也可生成本句。
- 提示词保留可点击图片ID引用，新增风格正文和台词绑定折叠区。提交快照包含图片引用映射、风格有效正文/版本、台词ID/内容与编译后提示词。
- 视频下方显示本镜模型、比例/像素、时长、分辨率，可单镜调整、恢复项目规格与生成。独立批量仅接收无尾帧依赖的合格镜头，原型演示最多3项并行；有尾帧依赖继续顺序生成。
- JSON文件可按下载模板导入；预检通过后确认，**全部新行整体替换旧表并刷新显示**。旧表归档，新表引用全部映射为新ID，媒体待生成。非法文件、失效引用、源版本冲突或保存失败均不替换旧表；重载后新表仍在。

## 二、验证与工程边界

V13契约测试覆盖字段/类型/枚举/范围/ID/引用、逐句配音隔离、单镜参数和风格台词编译。隔离浏览器覆盖六列表格、TTS小入口、单镜规格、并行状态、单镜失败不阻塞及仅重试失败项、尾帧依赖排除、四主题、JSON文件预检与整表替换、错误导入及存储失败回滚、重载保留。V5/V10原型数据回归、manifest验证、离线HTML导航与主链回归通过。测试文件为`reference/tests/workbenches-v13.mjs`和`workbenches-v13-browser.mjs`。

只读检查发现：现有后端BoardBody v2已有严格DTO、ID与摘要校验，但当前独立生成接口仅接受单镜。生产的导入事务/API/完整新表响应、并行批次调度、单镜覆盖和提示词编译仍需按R5 V13实施。原型的本地延迟和浏览器朗读不代表真实云端视频或TTS能力完成。

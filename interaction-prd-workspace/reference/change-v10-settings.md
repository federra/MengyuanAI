# V10 设置配置重构

本次修改交互 PRD、原型与技术契约，不涉及生产工程 M0/M1。

## 用户可见变化

右上角设置直接打开完整配置面板，不再经过入口弹窗。固定三个 Tab：模型配置、提示词配置、风格模板。音频模块并入模型配置，系统设置页也移除独立音频卡片。

模型按生文、生图、生视频、生音频分组。类别设默认，环节默认继承，可取消继承独立配置或恢复。保留旧环节配置作为覆盖；已有项目显式视频模型保持优先。提示词按场景显示模板下拉列表，支持编辑、新建、项目覆盖、变量预览，保存同时绑定所选场景；与资产库共用资源。工作台已经选定的方法仍保留。

## 数据与工程交接

原型增加 modelDefaults、projectPromptBindings，并复用 models 作为环节覆盖；系统场景绑定为 config.promptBindings。任务记录解析后的有效路由、来源、场景模板与版本，历史快照保持不变。真实服务应使用服务端模型路由 ID，不能仅替换模型显示名。

R5 新增分类默认和场景绑定的持久化、迁移及快照要求；08-settings.mmd/SVG 已同步。模型地址检查为格式校验，未接真实服务。样例生成、导出与本地缓存的既有边界保持。

## 模型导航紧凑化补充

按最新反馈，仅模型配置侧栏改为无边框文字树：父节点以 > / 向下符号展开收起，子环节缩进，行高约30px；提示词与风格模板保持原样。点击父节点仍可编辑类别默认，折叠不清除草稿。浏览器已验证鼠标/键盘展开收起、跨类别子节点路由、草稿保留、无边框行高以及提示词/风格 Tab 不受影响；浅色蓝与深色截图已检查，manifest 与 diff 格式检查通过。

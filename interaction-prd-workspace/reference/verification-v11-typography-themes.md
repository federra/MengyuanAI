# V11 无衬线排版与四主题验收

## 修改与边界

审核对象为交互 PRD 的11个原型页。原有菜单16px、标题28px合适，保留；统一正文、辅助、表单和章节字号，取消中文标题负字距，修复深色链接偏暗及原组件展示页字号不一致。所有页面加载同一 typography.css，字体使用本机无衬线回退，不声称已打包Satoshi字体。

新增第四主题“曜夜鎏金”（noir）：墨黑、暖灰、香槟金、细边框与柔和高光。原浅色/深色/晴空蓝保留，主题选择不更改业务内容、成片风格、素材图像。GSAP保留轻量位移和卡片进入，正文持续可读；减少动态偏好继续生效。

仅更新 PRD、Demo、R1/R2和导航。生产工程的模型能力、数据库、凭据、部署和验收状态不受本次更改影响。

## 已完成验证

- 1440×1000视口检查11页面×4主题共44组合：无页面脚本错误，无整页横向溢出；分镜表仍允许局部横滚。
- computed style检查统一sans-serif字体栈，正文15px、菜单16px、标题28px；Chrome平台字体接口确认标题中文实际为PingFang SC、品牌拉丁为SF，无远程字体依赖。
- 实际查看项目、故事、分镜、组件页及设置弹窗截图，涵盖原三主题与新增主题。
- 主题切换保留尚未保存的创意文本；刷新记住曜夜鎏金；同源另一个页面同步更新；模型文字树保持无边框。
- 对正文、辅助文字、链接与主按钮的主题配色进行对比度计算：四主题均超过4.5:1。最小值为晴空蓝辅助文字约4.88:1；深色按钮约5.02:1，曜夜鎏金按钮约10.00:1。此项针对指定颜色与面板底色，不代表全面无障碍认证。

复现脚本：`reference/tests/typography-v11-browser.mjs`（44组合）、`reference/tests/themes-v11-browser.mjs`（配色、主题与状态）。按本机环境配置 `PLAYWRIGHT_MODULE`，使用隔离浏览器上下文；不修改用户项目数据。历史V6主题记录保留原验收时点，不改写为四主题。

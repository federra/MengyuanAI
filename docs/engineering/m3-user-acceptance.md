## 五步独立操作

1. **创建与创意**：新建“我的M3独立试用”，选720P、16:9。输入一句话，例如“森林里，小松鼠把最后一颗果子送给小刺猬，两人坐在树下分享。”在创作要求中写明非真人卡通、仅上述两角色/一个场景/一个果子道具、三镜各4秒、全片最多两句短台词；生成一次故事候选并自行选定。
2. **故事与剧本**：阅读所选故事，必要时人工编辑保存，再生成一次剧本；保持总三镜和两句上限。AI质检建议可以不采用，避免增加本轮调用。保存自己认可的内容后生成一次分镜；若镜数、时长、台词不符，可人工修改表格并保存、确认，不能越过用量上限批量生成。
3. **图片与配音**：在分镜/元素入口准备两角色、场景和道具图，共4张，逐张检查与确认并绑定引用；生成3张站位图并确认。检查两句台词的音色、情绪和语速，生成最多2句配音，逐句试听。生成后再改台词会使配音过期，先检查预算再决定后续操作。
4. **三镜视频**：确认每镜4秒、720P和全部参考有效后，点击“按顺序生成全部镜头”，等待3镜完成；逐镜播放，核对后镜使用前镜真实尾帧。失败或未知先停止，记录任务与错误，不重新点击整批绕过原任务。
5. **真实导出**：进入“导出”，载入当前分镜与最新素材，保持3镜各4秒、24fps、配音与字幕开启，原声默认关闭，无配乐也可验收。检查两句开始时间与试听；如提示超长，调整可用镜头时长或先停止处理配音，不能关闭报错硬导出。保存剪辑 → 生成真实MP4 → 播放完整作品 → 下载并在本机播放器打开。刷新/退出再进应保留剪辑和下载；重复生成同一有效版本不新增成片。

停止当前开发服务后运行 `make dev-deepseek`，在终端隐藏输入密钥；只注入API/Worker当前进程，不写文件。已有环境凭据也可通过 `make dev` 继承。默认 `deepseek-v4-pro`、JSON Output、非思考模式、8192输出token上限，配置与提示词冻结在任务快照。

待用同一项目实际执行：一句话生成三方向 → 选定并人工改文保存 → 发送两轮导演要求 → 检查未采用前正文不变 → 采用并检查旧版 → 生成中刷新 → 实际失败后恢复。保存模型/提示词版本、任务与尝试ID、耗时、usage和供应商账单费用；人工检查中文市场、方向差异、因果与结局。费用不以usage估算冒充账单。

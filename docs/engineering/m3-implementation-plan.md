## 增量与依赖

1. `finishing`领域追加不可变剪辑版本与成片记录；剪辑保存使用revision冲突校验，冻结稳定shotId/lineId、媒体结果和项目规格。复用Job/Outbox/租约、StorageAdapter与现有来源有效性检查。相关文件：backend/finishing/{models,schemas,service,router}.py、增量迁移。
2. `finishing/render.py`确定性FFmpeg合成，H264/yuv420p、AAC/48kHz/stereo、可选24/25/30fps；继承项目尺寸，默认留边，可选择居中裁切，禁止拉伸。编码独立Worker执行，心跳、旧执行者写入保护、临时文件隔离；中断自动重算本地合成，不重投供应商。
3. 每镜指定裁剪起点和时长，不默认冻结末帧延长。逐句TTS按真实音频时长顺排，可设镜内起始时间；重叠与超长阻断，列明所需时长。字幕按完整句音频起止烧录，不猜逐词时间。禁用配音但启用字幕仍使用真实TTS对齐。默认关闭原视频声音；配音、原声、配乐分别调音量，混音不归一化缩短，限幅防削波。音乐先上传、全片循环、片尾结束并明确提示；不截断台词。
4. `FinishingWorkbench.tsx`以真实作品预览、侧配置、下方镜头列表实现保存/排序/裁剪/台词时序、音乐上传、提交/重试/历史下载。排序只改剪辑并要求确认连续性影响；使用公共panel/row/按钮/草稿与幂等命令。新增界面不扩展多轨编辑器。
5. 完成状态只在真实文件已落盘并检查成功、且来源与当前剪辑一致时更新。旧输出保留可下载并标过期；修改源内容/素材/规格或剪辑后恢复创作中，晚到输出不覆盖新状态。

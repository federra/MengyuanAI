## 实现与原因

三类管理的参考图与输出缩略图打开独立原比例完整图片窗口，可关闭或Esc返回；隔离内外窗口键盘事件，管理草稿保留，图片历史与选用通过“图片详情”独立入口。空槽无图不打开空预览。

四类分镜图片框右下角显示实际已关联文件数，包含0/1；没有文件的稳定元素占位不计数。新生成图片在成功落库事务中按显式entity_id更新当前分镜引用版本，角色/场景/道具走同一路径；站位图按shot_id追加所属镜头引用并保存分镜新版。不依赖用户打开管理窗口，不自动确认；来源过期或取消不绑定，重复完成不重复追加。站位不改变画面提示词，避免将自身结果错误标为过期。

“8848”的场景/道具已有图来自旧分镜目录；当前分镜使用另一个同名不同ID目录，且描述不同，因此不能凭名称悄悄归并。用户明确回复“复用这3张已有图片”后，使用现有原子entities/batch接口保存“护目镜、珠峰峰顶下方、珠峰北坡”三项新输出选择。旧实体/图片保留，目标新版本与稳定镜头引用持久化，3张图共覆盖6处镜头引用，全部待确认。准确来源/目标版本与文件映射见`evidence/image-preview-auto-reference/approved-reuse.json`；执行脚本` scripts/reuse-approved-8848-images.py`拒绝覆盖后来用户另选的图片。

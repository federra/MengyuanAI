## 真实项目检查

主项目：`M1 真实验收 · DeepSeek`，ID `9c975b3c-044f-41b2-8e7d-0173e6c21dbc`。故事 v3、剧本 v4、分镜 v2；实页确认 11 个镜头、15 条台词记录。使用已有长正文和质检报告，没有替换演示文本，也没有新增付费模型请求。

- 四主题分别检查项目、创意、故事、剧本、分镜、设置及模型弹窗，截图共 28 张。
- 1440px 视口下，分镜文档宽度 1425px；表格可见宽约 796px、内容宽 1271px，11 镜头在约 620px 的局部高度内滚动，没有把整页撑宽。
- 实际页面加载期间观察到读取状态，等待服务返回后再保存正式对照截图；项目首屏增加明确“正在读取项目”，避免把尚未加载误显示为零项目。加载锁定与失败恢复另由隔离 UI 回归验证。
- [真实失败记录](../../.local/ui-alignment/after/real-failed-jobs.png)：使用既有两条 invalid_model_output 失败，不重新触发付费失败任务。
- [真实空剧本](../../.local/ui-alignment/after/real-empty-script.png)：使用已有 `M0 验收 · 已保存并可继续` 项目；未生成内容时显示明确前置步骤。
- 实页将输出规格临时选为 1:1，关闭→模型配置→再开输出后仍为 1:1；随后恢复原 9:16，全程未保存到服务端。
- 凭据截图不回显密钥，本轮未填写、读取或修改密钥。

## 保留差异及原因

1. 原型候选缩略图、生成媒体和演示数量不等于生产数据。当前真实项目无封面/参考图时保留空状态，实际长文本和数量造成内容长度差异。
2. 生产保留保存基准、选择、版本历史、错误和任务恢复；原型部分操作把演示更新合在一起，不能为相似外观删除生产版本约束。
3. 配置树使用已有真实 API 环节名称；未把小说/剧本聚合演示节点硬映射成不存在的后端能力。真实密钥区位于模型表单下部，需要滚动查看。
4. TXT 导入、参考图/配音/视频批量生成、成片导出等后续能力未新增，也不显示可点击的虚假生成入口。

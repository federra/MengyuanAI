沿用 React/FastAPI/PostgreSQL/Celery/Redis/StorageAdapter，不另建服务或复制PRD Demo。新增 assets 领域负责项目元素与不可变版本；media负责文件探测、媒体结果及来源；jobs保留原文本执行，新增媒体提交/查询/下载及依赖放行。引用结构保存稳定身份与指定版本，保持M1既有UUID文件引用兼容。名称只影响显示；描述/图片/音色的变化按实际依赖使媒体待更新。来源变化期间晚到结果留在历史，不能自动成为当前结果。

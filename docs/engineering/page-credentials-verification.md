## 保护边界与操作

本地单用户OS账户受信任，Fernet认证加密不承诺抵御同账户恶意进程或主密钥与密文同时失窃。默认`.local/credentials/`，目录0700、文件0600；通过SHORTFILM_CREDENTIAL_ROOT可改为独立私有目录。普通备份只包含数据库和媒体，凭据目录缺失时重新在页面输入。Compose新增共享凭据卷，当前无Docker，未声称容器启动已实测。

系统设置 → 模型 → 生文 → 保存模型配置 → 输入并保存API密钥 → 测试已保存连接。连接测试是一次最多64输出token、HTTP超时参数不超过20秒（分阶段/无活动超时，非总耗时上限）的真实JSON探测，可能产生供应商用量；返回仅诊断状态、耗时与数字用量。密钥不回显、不写入浏览器草稿、配置历史、任务快照或普通备份。保存后API/Worker立即读取，环境变量方式仍兼容；已存凭据优先且严格绑定服务地址。

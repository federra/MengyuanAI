## 已实现

1. 项目卡右上角“…”菜单与删除确认。DELETE复用PG项目status软删除，按revision冲突保护，删除/恢复均幂等；活动及unknown任务阻止删除。列表/统计排除删除项目，通常项目接口返回404，数据和媒体历史保留；当前删除提示提供恢复按钮。删除错误直接显示在确认窗口，取消不写数据。
2. 共用标题右侧项目信息组件覆盖故事、剧本、分镜、导出，读取真实项目、类型、市场、风格、规格及已保存创意；12px、两行高度范围，长创意省略且悬停全文，不添加独立面板。项目修改后重新进入、窗口聚焦或10秒刷新可见。
3. 分镜表可滚动上限由620px提高到max(760px,视口高度减220px)；表头居中。四个64px槽位内以10px分别标明角色图/场景图/道具图/站位图。台词顶栏输入、麦克风及删除统一32px，后两者为32px方形，正文固定80px且内部滚动。
4. 三类管理七列表头居中；名称/音色/操作32px高。参考图与图片两列都有上传/清除，同排等宽32px。清除输出追加实体版本并解除显式镜头选用，保留原图/历史；清除生成预览后不会因刷新又显示旧图，新一轮生成仍可显示新结果。重新选择历史图片取消待清除标记。
5. 单行生图、详情生图和批量生图直接保存草稿并提交既有image-batches任务，删除整个确认面板和补充要求框。服务器仍校验配置/引用/版本并冻结快照，保留同步点击锁、原命令幂等、未知结果恢复与结果人工确认。此轮没有触发真实图片生成。

清除动作是EntityChange可选命令字段，不增加数据库列；普通保存规范化掉false默认值，兼容升级前已存命令摘要，保留未完成请求恢复。

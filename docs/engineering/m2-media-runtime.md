# M2 媒体运行依赖

本机新增 Homebrew 官方 ffmpeg 9.0.1_1（程序版本9.0.1），提供 ffmpeg、ffprobe、libx264；2026-09-09安装。新机器先安装对应平台FFmpeg，再运行媒体测试。Homebrew命令为 `brew install ffmpeg`；发行版随时间更新，实测版本以本文及工具输出为准，不声称该命令锁定同一二进制。容器固定构建仍未完成或验证。

媒体文件先探测实际格式、流、宽高、时长，再完整解码所选流；不信任扩展名或供应商自报时长。仅允许本地file/pipe协议，限制512MB、最长10小时及8192像素边长；调用有超时。末帧顺序解码所选视频流、逐帧覆盖同一输出图片，保留最后真实画面；因此较长音轨不会使定位越过视频末尾；不采用别镜、示例图或仅供应商预览图。

当前processing模块通过4项本地合成夹具测试：伪视频拒绝、1秒H.264视频探测及红色末帧、1.25秒WAV时长与流类型检查、1秒视频配4秒音频时的末帧。这些是确定性媒体工具验证，不是真实图像/TTS/视频供应商验收。
